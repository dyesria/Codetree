## 문제

실수값 $N$을 하나 입력받아 소수점 둘째자리까지 반올림하여 출력하는 프로그램을 작성해주세요.

## 입력

첫 번째 줄에는 $N$이 주어집니다.

## 제한 조건

- $0 \le N \le 50$

## 출력

입력받은 실수값을 소수점 둘째자리까지 반올림하여 출력합니다.

## 입력 예제

### 예제 1

입력

```text
22.4567
```

출력

```text
22.46
```

### 예제 2

입력

```text
15
```

출력

```text
15.00
```

## 제한

• Time Limit: 500 ms

• Memory Limit: 64 MiB
