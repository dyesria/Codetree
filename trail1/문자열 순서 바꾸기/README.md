## 문제

문자열 $S$와 문자열 $T$를 입력받아 순서를 바꾸어 출력하는 프로그램을 작성해보세요.

## 입력

첫 번째 줄에 문자열 $S$가, 두 번째 줄에 문자열 $T$가 차례대로 주어집니다. 단, 문자열 $S$와 $T$는 알파벳 소문자로만 이루어져있다고 가정해도 좋습니다.

## 제한 조건

- $1 \le \texttt{문자열 S의 길이, T의 길이} \le 100$

## 출력

첫 번째 줄에 문자열 $T$를, 두 번째 줄에 문자열 $S$를 출력합니다.

## 입력 예제

### 예제 1

입력

```text
code
tree
```

출력

```text
tree
code
```

• Time Limit: 500 ms
