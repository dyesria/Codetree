## 문제

$N$을 입력받아, $1$부터 $N$까지 공백을 두고 출력하는 프로그램을 작성해보세요.

## 입력

첫 번째 줄에 $N$이 주어집니다.

## 제한 조건

- $1 \le N \le 100$

## 출력

첫 번째 줄에 $1$부터 $N$까지의 정수를 공백을 사이에 두고 출력합니다.

## 입력 예제

### 예제 1

입력

```text
3
```

출력

```text
1 2 3
```

## 제한

• Time Limit: 500 ms

• Memory Limit: 64 MiB
