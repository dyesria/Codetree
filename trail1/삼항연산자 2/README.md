## 문제

정수 $a$가 주어졌을 때, $a$가 $1$이라면 `t` 를 출력하고, $1$이 아니라면 `f` 를 출력하는 프로그램 삼항연산자를 사용하여 작성해보세요.

## 입력

첫 번째 줄에 정수 $a$가 주어집니다.

## 제한 조건

- $0 \le a \le 100$

## 출력

첫 번째 줄에 a가 1이라면 `t` 를 출력하고, 1이 아니라면 `f` 를 출력합니다.

## 입력 예제

### 예제 1

입력

```text
1
```

출력

```text
t
```

### 예제 2

입력

```text
3
```

출력

```text
f
```
