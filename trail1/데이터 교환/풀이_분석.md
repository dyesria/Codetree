## 현재 풀이와 좋은 점

원래 b와 c를 임시변수에 보관해 세 값을 순환시킵니다. 덮어쓰기 전에 값을 저장했습니다.

## 다듬거나 기억할 부분

a를 하나만 보관하고 a=c,c=b,b=temp 순서로 옮기면 임시변수 하나로도 가능합니다. 자료형 크기는 작아 공간 절감보다 대입 순서를 이해하는 예시입니다.

## 복습 예시 코드

현재 풀이 구조를 유지한 완전한 C++ 실행 코드입니다. 원래 제출 소스는 변경하지 않습니다.

```cpp
#include <iostream>
using namespace std;

int main() {
    int a = 5; int b = 6; int c = 7;
    int tmp = b;
    int tmp2 = c;
    
    b = a;
    c = tmp;
    a = tmp2;

    cout << a << endl
         << b << endl
         << c;

    return 0;
}
```

## 작은 값으로 따라가기

(a,b,c)=(5,6,7) → 최종 (7,5,6). 각 변수에 어느 원래 값이 들어가야 하는지 먼저 적으면 안전합니다.

## 복잡도

시간·추가 공간 O(1).

## 확인 범위

문서의 예시 코드를 로컬 C++17 환경에서 컴파일하고, 문제 예제와 별도 확인 입력을 합해 1건의 출력을 대조했습니다. 비교 시 줄 끝 공백과 마지막 줄바꿈만 무시했습니다. 위 값 변화 설명은 코드 흐름을 수작업으로 추적한 내용입니다. 실행 시간 벤치마크나 코드트리 재제출은 하지 않았습니다.
