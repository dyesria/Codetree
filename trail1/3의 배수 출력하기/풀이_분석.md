## 현재 풀이와 좋은 점

1부터 N까지 순회하면서 3의 배수만 출력합니다. 마지막 값이 N일 때의 공백을 따로 처리합니다.

## 다듬거나 기억할 부분

3부터 3씩 증가하면 모든 후보가 3의 배수입니다. 검사를 줄이면서 마지막 값이 N인지 확인할 필요도 없어집니다. while문 학습은 유지합니다.

## 개선 예시 코드

설명한 개선을 적용한 완전한 C++ 실행 코드입니다. 원래 제출 소스는 변경하지 않습니다.

```cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;
    int i = 3;
    while (i <= n) {
        if (i > 3) cout << ' ';
        cout << i;
        i += 3;
    }
    return 0;
}
```

## 작은 값으로 따라가기

N=10이면 i는 3 → 6 → 9 → 12로 바뀌며 3 6 9만 출력합니다. 마지막 출력 값이 N일 필요는 없습니다.

## 복잡도

현재·예시 모두 시간 O(N), 추가 공간 O(1). 후보 수가 대략 N/3으로 줄어듭니다.

## 확인 범위

문서의 예시 코드를 로컬 C++17 환경에서 컴파일하고, 문제 예제와 별도 확인 입력을 합해 1건의 출력을 대조했습니다. 비교 시 줄 끝 공백과 마지막 줄바꿈만 무시했습니다. 위 값 변화 설명은 코드 흐름을 수작업으로 추적한 내용입니다. 실행 시간 벤치마크나 코드트리 재제출은 하지 않았습니다.
