## 문제

정수 $2$개를 입력받아 두 값중 최댓값을 출력하는 프로그램을 작성해보세요.

## 입력

첫 번째 줄에 정수 $A, B$가 공백을 사이에 두고 주어집니다.

## 제한 조건

- $1 \le A,\ B \le 100$

## 출력

첫 번째 줄에 최댓값을 출력합니다.

## 입력 예제

### 예제 1

입력

```text
2 5
```

출력

```text
5
```

### 예제 2

입력

```text
4 1
```

출력

```text
4
```
