## 현재 풀이와 좋은 점

하이픈을 char로 읽고 가운데·끝 숫자의 출력 순서를 바꿉니다. 정수로 읽으며 사라진 010의 앞 0을 출력에서 보충합니다.

## 다듬거나 기억할 부분

원문이 가운데·끝 네 자리가 0으로 시작하지 않는다고 보장하므로 현재 방식이 가능합니다. 표시 형식을 보존하고 싶다면 세 구간을 문자열로 읽는 대안이 자연스럽습니다. 범위 밖 입력을 현재 오류라고 단정하는 개선이 아닙니다.

## 개선 예시 코드

설명한 개선을 적용한 완전한 C++ 실행 코드입니다. 원래 제출 소스는 변경하지 않습니다.

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string prefix, middle, last;
    getline(cin, prefix, '-');
    getline(cin, middle, '-');
    getline(cin, last);
    cout << prefix << '-' << last << '-' << middle;
    return 0;
}
```

## 작은 값으로 따라가기

010-1234-5678을 세 문자열 010,1234,5678로 나눈 뒤 010-5678-1234로 연결합니다.

## 복잡도

현재는 고정 길이라 시간·공간 O(1). 문자열 길이를 L로 일반화하면 시간·공간 O(L).

## 확인 범위

문서의 예시 코드를 로컬 C++17 환경에서 컴파일하고, 문제 예제와 별도 확인 입력을 합해 3건의 출력을 대조했습니다. 비교 시 줄 끝 공백과 마지막 줄바꿈만 무시했습니다. 위 값 변화 설명은 코드 흐름을 수작업으로 추적한 내용입니다. 실행 시간 벤치마크나 코드트리 재제출은 하지 않았습니다.
