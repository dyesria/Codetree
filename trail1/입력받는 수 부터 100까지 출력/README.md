## 문제

100 이하의 정수 $n$을 입력받은 후, $n$부터 100까지의 숫자를 순서대로 출력하는 프로그램을 작성해보세요.

## 입력

첫 번째 줄에 $n$이 주어집니다.

## 제한 조건

- $1 \le n \le 100$

## 출력

첫 번째 줄에 $n$부터 100까지의 숫자를 공백을 사이에 두고 출력합니다.

## 입력 예제

### 예제 1

입력

```text
98
```

출력

```text
98 99 100
```

• Time Limit: 500 ms

• Memory Limit: 64 MiB
