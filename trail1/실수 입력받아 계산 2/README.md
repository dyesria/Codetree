## 문제

실수 $a$ 를 입력받아 $a$에 $1.5$를 더한 값을 소수점 아래 둘째자리까지 반올림하여 출력하는 프로그램을 작성해보세요.

## 입력

첫 번째 줄에 실수 $a$가 주어집니다.

## 제한 조건

- $1 \le a \le 100$

## 출력

첫 번째 줄에 실수 $a$에 $1.5$을 더한 값을 소수점 아래 둘째자리까지 반올림하여 출력합니다.

## 입력 예제

### 예제 1

입력

```text
5.26
```

출력

```text
6.76
```

• Time Limit: 500 ms

• Memory Limit: 64 MiB
