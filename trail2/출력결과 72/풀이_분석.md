## 핵심 원리

a+b<a+5는 수학적으로 b<5이고, 추가로 a==b여야 Lee를 출력합니다.

## 순서대로 따라가기

보기 중 f(3,3)은 3<5와 3==3을 모두 만족합니다. f(3,5)는 첫 조건부터 거짓입니다.

## 기억할 부분

사용하지 않는 d,e는 실행 결과에 영향을 주지 않습니다. 아래 복습 예시는 함수 호출 f(3,3)을 덧붙여 출력 여부를 확인합니다.

## 복습 예시 코드

제시 코드를 C++에서 확인하기 위한 완전한 실행 예시입니다. 필요한 main·출력을 보충하거나 위 설명에 맞게 정리했습니다.

```cpp
#include <iostream>
using namespace std;

void f(int a, int b) {  
    int c, d = 0, e = 17;  
    c = a + 5;  
    if (a + b < c) {     
        if (a == b) {      
            cout << "Lee";
        }     
    }
}

int main() {
    f(3, 3);
    return 0;
}
```

## 복잡도

시간·공간 O(1).

## 확인 범위

문서의 예시 코드를 로컬 C++17 환경에서 컴파일하고, 복습 확인 입력 1건의 출력을 대조했습니다. 비교 시 줄 끝 공백과 마지막 줄바꿈만 무시했습니다. 위 값 변화 설명은 코드 흐름을 수작업으로 추적한 내용입니다. 실행 시간 벤치마크나 코드트리 재제출은 하지 않았습니다.
