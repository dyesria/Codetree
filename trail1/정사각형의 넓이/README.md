## 문제

한 변의 길이가 $N$인 정사각형의 넓이를 구하는 프로그램을 작성해보세요.

단, $N$이 $5$보다 작다면 `tiny` 를 출력합니다.

## 입력

첫 번째 줄에 자연수 $N$이 주어집니다.

## 제한 조건

- $1 \le N \le 100$

## 출력

첫 번째 줄에, 정사각형의 넓이를 출력합니다.

$N$이 $5$보다 작다면 두 번째 줄에  `tiny` 를 출력합니다.

## 입력 예제

### 예제 1

입력

```text
5
```

출력

```text
25
```

### 예제 2

입력

```text
4
```

출력

```text
16
tiny
```
