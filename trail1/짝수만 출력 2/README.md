## 문제

두 정수 $B$와 $A$가 주어지면 $A$이상 $B$이하의 짝수를 모두 내림차순으로 출력하는 프로그램을 작성해보세요.

단, `while`문을 사용하여 해결해봅니다.

## 입력

첫 번째 줄에 정수 $B$와 $A$가 공백을 두고 주어집니다.

## 제한 조건

- $1 \le A \le B \le 50$
- $A, B$는 짝수

## 출력

첫 번째 줄에 $A$부터 $B$까지의 자연수중 짝수들만 공백을 두고 내림차순으로 출력합니다.

## 입력 예제

### 예제 1

입력

```text
20 10
```

출력

```text
20 18 16 14 12 10
```

## 제한

• Time Limit: 500 ms

• Memory Limit: 64 MiB
