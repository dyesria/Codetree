## 문제

$n, m$이 주어졌을 때, 전부 $1$로 이루어져 있는 $n \times m$ 크기의 직사각형을 출력하는 프로그램을 작성해보세요. 단, 직사각형의 행, 열의 크기를 인자로 받아 직사각형을 출력하는 함수를 만들어 문제를 해결해주세요.

## 입력

첫 번째 줄에 정수 $n$과 $m$이 공백을 사이에 두고 주어집니다.

## 제한 조건

- $1 \le n \le 100$
- $1 \le m \le 100$

## 출력

$1$로 이루어진 $n \times m$ 크기의 직사각형을 출력합니다.

## 입력 예제

### 예제 1

입력

```text
2 3
```

출력

```text
111
111
```

## 제한

• Time Limit: 500 ms

• Memory Limit: 64 MiB
