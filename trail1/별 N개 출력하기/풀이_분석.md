## 현재 풀이와 좋은 점

N을 1씩 줄이며 별을 줄마다 출력합니다. 출력 횟수와 감소 연산이 대응합니다.

## 다듬거나 기억할 부분

현재처럼 입력값을 카운터로 사용해도 문제없습니다. 나중에 원래 N이 필요할 경우에만 별도 remaining 변수를 두면 됩니다.

## 복습 예시 코드

현재 풀이 구조를 유지한 완전한 C++ 실행 코드입니다. 원래 제출 소스는 변경하지 않습니다.

```cpp
#include <iostream>
using namespace std;

int main() {
    int N;
    cin >> N;

    while(1 <= N) {
        cout << "*" << endl;
        N--;
    }
    
    return 0;
}
```

## 작은 값으로 따라가기

N=3이면 출력 후 남은 N이 2,1,0이 되어 세 줄을 출력합니다.

## 복잡도

시간 O(N), 추가 공간 O(1).

## 확인 범위

문서의 예시 코드를 로컬 C++17 환경에서 컴파일하고, 문제 예제와 별도 확인 입력을 합해 1건의 출력을 대조했습니다. 비교 시 줄 끝 공백과 마지막 줄바꿈만 무시했습니다. 위 값 변화 설명은 코드 흐름을 수작업으로 추적한 내용입니다. 실행 시간 벤치마크나 코드트리 재제출은 하지 않았습니다.
