## 현재 풀이와 좋은 점

시·분 사이 문자를 cin.get()으로 소비하고 시에 1을 더합니다. 입력 형식과 출력 형식을 연결했습니다.

## 다듬거나 기억할 부분

구분 문자를 char separator로 받으면 무엇을 읽는지 더 분명합니다. 문제에 없는 24시간 순환이나 두 자리 0 채우기는 임의로 추가하지 않습니다.

## 복습 예시 코드

현재 풀이 구조를 유지한 완전한 C++ 실행 코드입니다. 원래 제출 소스는 변경하지 않습니다.

```cpp
#include <iostream>
using namespace std;

int main() {
    int h; int m;

    cin >> h;
    cin.get();
    cin >> m;
    
    cout << h+1 << ":" << m;
    return 0;
}
```

## 작은 값으로 따라가기

3:20을 읽으면 h=3,m=20이고 출력은 4:20입니다.

## 복잡도

시간·추가 공간 O(1).

## 확인 범위

문서의 예시 코드를 로컬 C++17 환경에서 컴파일하고, 문제 예제와 별도 확인 입력을 합해 2건의 출력을 대조했습니다. 비교 시 줄 끝 공백과 마지막 줄바꿈만 무시했습니다. 위 값 변화 설명은 코드 흐름을 수작업으로 추적한 내용입니다. 실행 시간 벤치마크나 코드트리 재제출은 하지 않았습니다.
