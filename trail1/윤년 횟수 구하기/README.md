## 문제

$N$이 주어지면 $1$년부터 $N$년까지 윤년이 총 몇 번 있었는지를 구하는 프로그램을 작성해보세요. 윤년의 조건은 다음과 같습니다.

- $4$로 나누어 떨어지는 해는 윤년, 그 밖의 해는 평년입니다.

- 단, 예외적으로 $100$으로 나누어 떨어지되 $400$으로 나누어 떨어지지 않는 해는 평년으로 합니다.

## 입력

첫 번째 줄에 $N$의 값이 주어집니다.

## 제한 조건

- $1 \le N \le 2\,021$

## 출력

윤년의 수를 출력합니다.

## 입력 예제

### 예제 1

입력

```text
100
```

출력

```text
24
```

### 예제 2

입력

```text
1000
```

출력

```text
242
```

• Time Limit: 500 ms

• Memory Limit: 64 MiB
