## 문제

정수 $a$, $b$를 입력받고, $a$와 $b$를 곱해준 값을 출력하는 프로그램을 작성해보세요.

## 입력

첫 번째 줄에 정수 $a$가 주어집니다.

두 번째 줄에 정수 $b$가 주어집니다.

## 제한 조건

- $1 \le a, b \le 100$

## 출력

첫 번째 줄에 $a$와 $b$를 곱해준 값을 출력합니다.

## 입력 예제

### 예제 1

입력

```text
34
63
```

출력

```text
2142
```

## 제한

• Time Limit: 500 ms

• Memory Limit: 64 MiB
