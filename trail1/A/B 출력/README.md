## 문제

두 정수 $A$와 $B$가 주어집니다.

실수 $A/B$의 값을 소수점 $21$번째 자리에서 내림하여 출력하는 프로그램을 작성해보세요.

## 입력

첫 줄에 두 정수 $A$와 $B$가 공백으로 구분되어 주어집니다.

## 제한 조건

- $1 \le A, B \le 100$

## 출력

첫 줄에 $A / B$의 값을 소수점 $21$번째 자리에서 내림하여 출력합니다.

## 입력 예제

### 예제 1

입력

```text
14 3
```

출력

```text
4.66666666666666666666
```

### 예제 2

입력

```text
3 5
```

출력

```text
0.60000000000000000000
```

### 예제 3

입력

```text
3 7
```

출력

```text
0.42857142857142857142
```

## 힌트

$20$번째 자리까지 format을 이용하여 한 번에 출력하는 것은 쉽지 않습니다.

## 제한

• Time Limit: 500 ms

• Memory Limit: 64 MiB
