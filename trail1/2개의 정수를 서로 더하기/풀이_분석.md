## 현재 풀이와 좋은 점

a를 먼저 갱신한 뒤 바뀐 a를 b에 더합니다. 두 대입의 순서를 지켰습니다.

## 다듬거나 기억할 부분

두 줄은 동시에 계산되는 것이 아닙니다. 원래 a,b의 합을 양쪽에 넣도록 바꾸면 문제 의미가 달라집니다.

## 복습 예시 코드

현재 풀이 구조를 유지한 완전한 C++ 실행 코드입니다. 원래 제출 소스는 변경하지 않습니다.

```cpp
#include <iostream>
using namespace std;

int main() {
    int a; int b;
    cin >> a >> b;

    a += b;
    b += a;

    cout << a << ' ' << b;
    return 0;
}
```

## 작은 값으로 따라가기

a=2,b=3 → a=5,b=3 → a=5,b=8입니다.

## 복잡도

시간·추가 공간 O(1).

## 확인 범위

문서의 예시 코드를 로컬 C++17 환경에서 컴파일하고, 문제 예제와 별도 확인 입력을 합해 1건의 출력을 대조했습니다. 비교 시 줄 끝 공백과 마지막 줄바꿈만 무시했습니다. 위 값 변화 설명은 코드 흐름을 수작업으로 추적한 내용입니다. 실행 시간 벤치마크나 코드트리 재제출은 하지 않았습니다.
