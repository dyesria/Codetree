## 문제

문자 $c$를 하나 입력받아 그대로 출력하는 프로그램을 작성해주세요.

## 입력

첫 번째 줄에는 $c$가 주어집니다. 항상 알파벳만 주어진다고 가정해도 좋습니다.

## 제한 조건

- $c$는 알파벳입니다.

## 출력

입력받은 문자를 출력합니다.

## 입력 예제

### 예제 1

입력

```text
c
```

출력

```text
c
```

### 예제 2

입력

```text
A
```

출력

```text
A
```

• Time Limit: 500 ms

• Memory Limit: 64 MiB
