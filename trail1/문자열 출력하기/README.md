## 문제

정수 $N$의 값을 입력받고 그 값의 횟수만큼 `LeebrosCode`를 출력하는 프로그램을 작성해보세요.

## 입력

첫 번째 줄에 정수 $N$이 주어집니다.

## 제한 조건

- $1 \le N \le 10$

## 출력

입력받은 값의 횟수만큼 `LeebrosCode`를 줄에 한 번씩 출력합니다.

## 입력 예제

### 예제 1

입력

```text
6
```

출력

```text
LeebrosCode
LeebrosCode
LeebrosCode
LeebrosCode
LeebrosCode
LeebrosCode
```

## 제한

• Time Limit: 500 ms

• Memory Limit: 64 MiB
