## 현재 풀이와 좋은 점

3의 배수 여부와 5의 배수 여부를 따로 출력합니다.

## 다듬거나 기억할 부분

두 결과가 각각 필요하므로 else if 하나로 합치면 안 됩니다. 현재 독립된 if 구조가 적절합니다.

## 복습 예시 코드

현재 풀이 구조를 유지한 완전한 C++ 실행 코드입니다. 원래 제출 소스는 변경하지 않습니다.

```cpp
#include <iostream>
using namespace std;

int main() {
    int A;

    cin >> A;

    if (A % 3 == 0) {
        cout << "YES" << endl;
    } else {
        cout << "NO" << endl;
    }

    if (A % 5 == 0) {
        cout << "YES" << endl;
    } else {
        cout << "NO" << endl;
    }
    return 0;
}
```

## 작은 값으로 따라가기

15는 YES와 YES, 9는 YES와 NO를 각각 두 줄에 출력합니다.

## 복잡도

시간·추가 공간 O(1).

## 확인 범위

문서의 예시 코드를 로컬 C++17 환경에서 컴파일하고, 문제 예제와 별도 확인 입력을 합해 2건의 출력을 대조했습니다. 비교 시 줄 끝 공백과 마지막 줄바꿈만 무시했습니다. 위 값 변화 설명은 코드 흐름을 수작업으로 추적한 내용입니다. 실행 시간 벤치마크나 코드트리 재제출은 하지 않았습니다.
