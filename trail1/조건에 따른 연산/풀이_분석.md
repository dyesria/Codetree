## 현재 풀이와 좋은 점

짝수·홀수에 맞는 식을 적용해 1000 이상이 될 때까지 반복합니다. continue를 사용해 한 번의 반복에 연산이 두 번 적용되지 않도록 했습니다.

## 다듬거나 기억할 부분

if/else로 둘 중 하나만 수행하면 continue 두 개와 중복된 cnt++를 없앨 수 있습니다. 홀수·짝수 판단은 변환 전 값에 대해 한 번만 해야 합니다.

## 개선 예시 코드

설명한 개선을 적용한 완전한 Java 실행 코드입니다. 원래 제출 소스는 변경하지 않습니다.

```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        int n = scanner.nextInt();
        int count = 0;
        while (n < 1000) {
            if (n % 2 == 0) n = n * 3 + 1;
            else n = n * 2 + 2;
            ++count;
        }
        System.out.print(count);
    }
}
```

## 작은 값으로 따라가기

2(짝수) → 7(홀수) → 16(짝수) → 49 → 100 → 301 → 604 → 1813입니다. 화살표 하나가 연산 한 번이므로 총 7회입니다.

## 복잡도

실제 변환 횟수 T에 대해 시간 O(T), 추가 공간 O(1). 양의 입력은 매번 적어도 두 배가 되므로 빠르게 종료됩니다.

## 확인 범위

문서의 예시 코드를 로컬 Java 21 환경에서 컴파일하고, 문제 예제와 별도 확인 입력을 합해 2건의 출력을 대조했습니다. 비교 시 줄 끝 공백과 마지막 줄바꿈만 무시했습니다. 위 값 변화 설명은 코드 흐름을 수작업으로 추적한 내용입니다. 실행 시간 벤치마크나 코드트리 재제출은 하지 않았습니다.
