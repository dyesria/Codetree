## 문제

정수 $a$를 입력받아, $a$에 $2$를 곱하고, $3$을 더해서, 출력하는 프로그램을 작성해보세요.

## 입력

첫 줄에 정수 $a$가 주어집니다.

## 제한 조건

- $1 \le a \le 100$

## 출력

첫 줄에 입력받은 정수 $a$에 $2$를 곱하고 $3$을 더한 값을 출력합니다.

## 입력 예제

### 예제 1

입력

```text
4
```

출력

```text
11
```

## 제한

• Time Limit: 500 ms

• Memory Limit: 64 MiB
