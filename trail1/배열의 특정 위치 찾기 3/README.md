## 문제

정수가 차례로 주어지다가 $0$이 주어지면 처음으로 주어진 $0$에 대해서 앞의 $3$개를 수를 더하여 출력하는 프로그램을 배열을 사용하여 작성해보세요. (단, $0$은 네 번째 이후부터 주어진다고 가정해도 좋습니다.)

## 입력

첫 번째 줄에 최대 $100$ 개의 정수가 공백을 사이에 두고 주어집니다.

## 제한 조건

- $-100 \le \texttt{주어지는 정수} \le 100$

## 출력

첫 번째 줄에 $0$을 기준으로 마지막으로 주어진 $3$개의 정수의 합을 출력합니다.

## 입력 예제

### 예제 1

입력

```text
1 2 3 0 5 5 5 6 0
```

출력

```text
6
```

### 예제 2

입력

```text
1 -3 5 -7 9 10 12 13 15 0
```

출력

```text
40
```

## 제한

• Time Limit: 500 ms

• Memory Limit: 64 MiB
