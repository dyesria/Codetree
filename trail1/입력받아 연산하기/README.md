## 문제

정수 $2$개를 입력받아서 첫 번째 수에는 $87$을 증가시켜 저장하고 두 번째 수는 $10$으로 나눈 나머지를 저장한 후 두 수를 차례로 출력하는 프로그램을 작성해보세요.

## 입력

한 줄에 하나씩  두 정수 $a$, $b$가 주어집니다.

## 제한 조건

- $1 \le a, b \le 500$

## 출력

첫 번째 줄에는 정수 $a$를 $87$증가시킨 값을,

두 번째 줄에는 정수 $b$를 $10$으로 나눈 나머지의 값을 출력합니다.

## 입력 예제

### 예제 1

입력

```text
13
87
```

출력

```text
100
7
```

## 제한

• Time Limit: 500 ms

• Memory Limit: 64 MiB
