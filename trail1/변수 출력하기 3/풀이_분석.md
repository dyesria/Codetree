## 현재 풀이와 좋은 점

정수 두 개와 문자 하나를 -> 기호로 연결합니다.

## 다듬거나 기억할 부분

char와 int를 목적에 맞게 선택했습니다. 출력 순서를 바꾸면 결과가 달라지므로 현재 연결 순서를 유지하세요.

## 복습 예시 코드

현재 풀이 구조를 유지한 완전한 C++ 실행 코드입니다. 원래 제출 소스는 변경하지 않습니다.

```cpp
#include <iostream>
using namespace std;

int main() {
    int a = 1;
    int b = 2;
    char c = 'C';

    cout << a << "->" << b << "->" << c;

    return 0;
}
```

## 작은 값으로 따라가기

a=1,b=2,c='C'이므로 1->2->C입니다.

## 복잡도

시간·추가 공간 O(1).

## 확인 범위

문서의 예시 코드를 로컬 C++17 환경에서 컴파일하고, 문제 예제와 별도 확인 입력을 합해 1건의 출력을 대조했습니다. 비교 시 줄 끝 공백과 마지막 줄바꿈만 무시했습니다. 위 값 변화 설명은 코드 흐름을 수작업으로 추적한 내용입니다. 실행 시간 벤치마크나 코드트리 재제출은 하지 않았습니다.
