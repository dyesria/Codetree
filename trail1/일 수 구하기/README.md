## 문제

윤년이 아닌 해에 $n$월에는 며칠이 있는지를 출력하는 프로그램을 작성하세요. 윤년이 아닌 해의 $2$월은 $28$일까지 있습니다.

## 입력

첫 번째 줄에 n이 주어집니다.

## 제한 조건

- $1 \le n \le 12$

## 출력

해당 월의 일 수를 출력합니다.

## 입력 예제

### 예제 1

입력

```text
1
```

출력

```text
31
```

### 예제 2

입력

```text
2
```

출력

```text
28
```

## 제한

• Time Limit: 500 ms

• Memory Limit: 64 MiB
