## 문제

$2$의 거듭제곱수 중 하나인 $N$을 입력받아, $N = 2^x$ 를 만족하는 $x$ 값을 구하는 코드를 작성해보세요.

## 입력

첫 번째 줄에 $N$이 주어집니다.

## 제한 조건

- $2 \le N \le 1\,024$

## 출력

$x$값을 출력합니다.

## 입력 예제

### 예제 1

입력

```text
4
```

출력

```text
2
```

• Time Limit: 500 ms
