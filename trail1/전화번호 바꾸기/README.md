## 문제

`010-xxxx-yyyy` 형태의 전화번호를 입력받아 앞 $4$자리와 뒤 $4$자리를 바꾸어 출력하는 프로그램을 작성해보세요.

## 입력

첫 번째 줄에 전화번호가 `010-xxxx-yyyy`의 형태로 주어집니다. `xxxx`와 `yyyy`는 $0$으로 시작되지 않음을 가정해도 좋습니다.

## 제한 조건

- $1 \le x, y \le 9$

## 출력

입력받은 전화번호를 `010-yyyy-xxxx`의 형태로 출력합니다.

## 입력 예제

### 예제 1

입력

```text
010-1234-5678
```

출력

```text
010-5678-1234
```

### 예제 2

입력

```text
010-8765-4321
```

출력

```text
010-4321-8765
```
