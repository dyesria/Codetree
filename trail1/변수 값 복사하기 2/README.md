## 문제

정수 $a$, $b$, $c$에 각각 값 $5$, $6$, $7$을 넣고 $c$의 값을 $a$, $b$에 복사한 뒤, $a$, $b$, $c$ 의 값을 차례로 출력하는 프로그램을 작성해보세요.

## 입력

입력이 주어지지 않습니다.

## 출력

결과값 $a$, $b$, $c$를 공백을 사이에 두고 출력합니다.

## 입력 예제

### 예제 1

출력

```text
7 7 7
```
