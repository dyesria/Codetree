## 문제

중간고사를 $90$점 이상 받은 자들로 한해서, 기말고사 점수에 따라 장학금을 지급하기로 했습니다. 기말고사 점수가 $100$점 만점에 $95$점 이상은 $10$만 원, $90$점 이상은 $5$만 원, 그 미만 점수는 받지 못합니다. 중간, 기말고사 점수를 입력했을 때 받을 수 있는 장학금을 출력하는 프로그램을 작성해주세요.

## 입력

첫 번째 줄에 중간, 기말고사 점수가 공백을 사이에 두고 차례대로 주어집니다.

## 제한 조건

- $0 \le \texttt{중간, 기말고사 점수} \le 100$

## 출력

조건을 충족시키는 장학금을 출력해줍니다.

## 입력 예제

### 예제 1

입력

```text
82 95
```

출력

```text
0
```

### 예제 2

입력

```text
90 95
```

출력

```text
100000
```

• Time Limit: 500 ms
