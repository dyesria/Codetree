## 문제

$100$ 이하의 정수 $N$을 입력받은 후, $N$부터 $100$까지의 합을 구하는 프로그램을 작성해보세요.

## 입력

첫 번째 줄에 $N$이 주어집니다.

## 제한 조건

- $1 \le N \le 100$

## 출력

첫 번째 줄에 $N$부터 $100$까지의 합을 출력합니다.

## 입력 예제

### 예제 1

입력

```text
91
```

출력

```text
955
```

## 제한

• Time Limit: 500 ms

• Memory Limit: 64 MiB
