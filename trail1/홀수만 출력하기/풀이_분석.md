## 현재 풀이와 좋은 점

입력을 하나씩 읽으며 홀수와 3의 배수 조건을 AND로 결합해 통과한 값만 출력합니다. 배열 없이 순서를 그대로 유지합니다.

## 다듬거나 기억할 부분

이미 필요한 작업만 수행합니다. input보다 value처럼 값의 역할을 나타내는 이름을 쓰는 것은 선택적인 가독성 개선입니다. 모든 입력을 읽어야 하므로 반복 자체를 없앨 수는 없습니다.

## 복습 예시 코드

현재 풀이 구조를 유지한 완전한 C++ 실행 코드입니다. 원래 제출 소스는 변경하지 않습니다.

```cpp
#include <iostream>
using namespace std;

int main() {
    int N;
    int input;

    cin >> N;
    for (int i=1; i<=N; i++) {
        cin >> input;

        if (input % 2 != 0 && input % 3 == 0) {
            cout << input << endl;
        }
    }
    return 0;
}
```

## 작은 값으로 따라가기

2와 7은 제외, 3과 9는 각각 출력, 4는 제외합니다. 홀수이기만 한 7은 출력되지 않습니다.

## 복잡도

시간 O(N), 추가 공간 O(1).

## 확인 범위

문서의 예시 코드를 로컬 C++17 환경에서 컴파일하고, 문제 예제와 별도 확인 입력을 합해 1건의 출력을 대조했습니다. 비교 시 줄 끝 공백과 마지막 줄바꿈만 무시했습니다. 위 값 변화 설명은 코드 흐름을 수작업으로 추적한 내용입니다. 실행 시간 벤치마크나 코드트리 재제출은 하지 않았습니다.
