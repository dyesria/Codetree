## 문제

다음과 같이 별 $10$개를 찍는 것을 $5$번 반복하는 프로그램을 작성해보세요. 단, 정확히 별 $10$개를 출력하는 함수를 만들어 이를 $5$번 호출하여 문제를 해결해주세요.

## 입력

이 문제는 입력이 주어지지 않습니다.

## 출력

총 $5$개의 줄을 출력합니다. 각 줄에는 별 문자 `*`를 정확히 $10$개씩 출력합니다.
