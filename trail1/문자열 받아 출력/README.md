## 문제

문자열 $S$를 하나 입력받아 그대로 출력하는 프로그램을 작성해주세요.

## 입력

첫 번째 줄에는 $S$가 주어집니다. 문자열 $S$는 알파벳으로만 이루어져 있다고 가정해도 좋습니다.

## 제한 조건

$1 \le \texttt{문자열 } S \texttt{의 길이} \le 100$

## 출력

입력받은 문자열을 출력합니다.

## 입력 예제

### 예제 1

입력

```text
caT
```

출력

```text
caT
```

### 예제 2

입력

```text
AppLe
```

출력

```text
AppLe
```

## 제한

• Time Limit: 500 ms

• Memory Limit: 64 MiB
