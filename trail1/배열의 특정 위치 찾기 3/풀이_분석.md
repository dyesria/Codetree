## 현재 풀이와 좋은 점

한 줄을 stringstream으로 나눠 배열에 저장하고 첫 0의 인덱스 바로 앞 세 값을 더합니다. 첫 0에서 멈추는 점이 요구에 맞습니다.

## 다듬거나 기억할 부분

공백 구분 정수는 cin으로 바로 읽어도 됩니다. 배열을 사용하라는 학습 조건을 유지하면서 줄 문자열과 stringstream을 줄일 수 있습니다. 원문은 0 앞에 최소 세 수가 있다고 보장하므로 그 범위 내에서 인덱스는 유효합니다.

## 개선 예시 코드

설명한 개선을 적용한 완전한 C++ 실행 코드입니다. 원래 제출 소스는 변경하지 않습니다.

```cpp
#include <iostream>
using namespace std;

int main() {
    int numbers[100];
    int count = 0;
    while (count < 100 && cin >> numbers[count]) {
        if (numbers[count] == 0) break;
        ++count;
    }
    cout << numbers[count - 3] + numbers[count - 2]
         + numbers[count - 1];
    return 0;
}
```

## 작은 값으로 따라가기

1, -3, 5, -7, 9, 10, 12, 13, 15, 0이면 0 직전 세 값은 12, 13, 15이고 합은 40입니다.

## 복잡도

읽은 수를 K라 하면 시간 O(K). 고정 100칸 배열은 공간 O(1); 용량을 K로 늘리면 O(K).

## 확인 범위

문서의 예시 코드를 로컬 C++17 환경에서 컴파일하고, 문제 예제와 별도 확인 입력을 합해 2건의 출력을 대조했습니다. 비교 시 줄 끝 공백과 마지막 줄바꿈만 무시했습니다. 위 값 변화 설명은 코드 흐름을 수작업으로 추적한 내용입니다. 실행 시간 벤치마크나 코드트리 재제출은 하지 않았습니다.
