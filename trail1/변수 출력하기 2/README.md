## 문제

변수 $a$, $b$에 각각 $3$, `C`을 넣어주고, 출력 형식에 알맞게 출력하는 프로그램을 작성하세요.

## 입력

입력이 주어지지 않습니다.

## 출력

$b, a$의 값을 순서대로 출력하되 사이에 `!.....!`를 포함합니다.

## 입력 예제

### 예제 1

출력

```text
C!.....!3
```

• Time Limit: 500 ms

• Memory Limit: 64 MiB
