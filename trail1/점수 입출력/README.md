## 문제

점수를 입력받아 출력 예시와 같은 포맷으로 출력하는 프로그램을 작성해보세요.

## 입력

첫 번째 줄에는 점수에 해당하는 정수 $N$이 주어집니다.

## 제한 조건

- $1 \le N \le 1\,000$

## 출력

입력받은 점수 $N$에 대하여 `Your score is N point.` 와 같은 형식으로 출력하세요.

## 입력 예제

### 예제 1

입력

```text
143
```

출력

```text
Your score is 143 point.
```

## 제한

• Time Limit: 500 ms

• Memory Limit: 64 MiB
