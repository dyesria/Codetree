## 문제

세 수 $A, B, C$의 값이 주어졌을 때, $B$가 $A$보다 크고 $C$보다 작다면 $1$을, 그렇지 않다면 $0$을 출력하는 프로그램을 작성해보세요.

## 입력

첫 번째 줄에 $A, B, C$값을 순서대로 공백을 두고 주어집니다.

## 제한 조건

- $1 \le A, B, C \le 100$

## 출력

$B$가 $A$보다 크고 $C$보다 작다면 $1$을, 그렇지 않다면 $0$을 출력하는 프로그램을 작성해보세요.

## 입력 예제

### 예제 1

입력

```text
1 2 3
```

출력

```text
1
```

### 예제 2

입력

```text
1 2 2
```

출력

```text
0
```
