## 현재 풀이와 좋은 점

10개 입력 중 n % 2 != 0인 수를 셉니다. 이름과 달리 문제의 실제 요구인 홀수 개수를 조건에 반영했습니다.

## 다듬거나 기억할 부분

cnt를 oddCount로 바꾸면 어떤 개수인지 더 바로 읽힙니다. 로직 자체는 이미 간결하여 별도 알고리즘 변경이 필요하지 않습니다.

## 복습 예시 코드

현재 풀이 구조를 유지한 완전한 C++ 실행 코드입니다. 원래 제출 소스는 변경하지 않습니다.

```cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    int cnt=0;
    for (int i=1; i<=10; i++) {
        cin >> n;

        if (n % 2 != 0) {
            cnt++;
        }
    }
    cout << cnt;
    return 0;
}
```

## 작은 값으로 따라가기

5를 읽으면 1, 10과 2를 읽어도 1, 7을 읽으면 2가 됩니다. 입력을 모두 읽은 뒤 한 번 출력합니다.

## 복잡도

고정 10개이므로 시간·추가 공간 O(1). K개라면 시간 O(K).

## 확인 범위

문서의 예시 코드를 로컬 C++17 환경에서 컴파일하고, 문제 예제와 별도 확인 입력을 합해 1건의 출력을 대조했습니다. 비교 시 줄 끝 공백과 마지막 줄바꿈만 무시했습니다. 위 값 변화 설명은 코드 흐름을 수작업으로 추적한 내용입니다. 실행 시간 벤치마크나 코드트리 재제출은 하지 않았습니다.
