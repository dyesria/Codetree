## 문제

`mm-dd-yyyy` 모양의 날짜 정보를 입력받아 `yyyy.mm.dd` 형식으로 출력하는 프로그램을 작성해보세요.

## 입력

첫 번째 줄에 날짜 정보가 `mm-dd-yyyy` 형태로 주어집니다. yyyy는 연도를, mm은 월을, dd는 일을 의미합니다.

## 제한 조건

- $1 \le yyyy \le 2021$
- $1 \le mm \le 12$
- $1 \le dd \le 28$

## 출력

입력받은 날짜를 `yyyy.mm.dd` 형식으로 바꾸어 출력합니다.

## 입력 예제

### 예제 1

입력

```text
5-26-1994
```

출력

```text
1994.5.26
```

### 예제 2

입력

```text
2-28-1
```

출력

```text
1.2.28
```
