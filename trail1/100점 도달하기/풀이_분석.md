## 현재 풀이와 좋은 점

현재 점수부터 100까지 순회하며 높은 등급부터 검사합니다. 90 이상을 먼저 검사해 중복 범위 문제를 피했습니다.

## 다듬거나 기억할 부분

조건과 출력이 이미 명확합니다. 등급 계산을 여러 곳에서 쓸 때만 grade(score) 함수로 분리하면 됩니다. 한 번만 쓰는 현재 코드에 함수화를 강요할 필요는 없습니다.

## 복습 예시 코드

현재 풀이 구조를 유지한 완전한 C++ 실행 코드입니다. 원래 제출 소스는 변경하지 않습니다.

```cpp
#include <iostream>
using namespace std;

int main() {
    int N;
    cin >> N;

    for (int i=N; i<=100; i++) {
        if (i >= 90) {
            cout << 'A';
        } else if (i >= 80) {
            cout << 'B';
        } else if (i >= 70) {
            cout << 'C';
        } else if (i >= 60) {
            cout << 'D';
        } else {
            cout << 'F';
        }
        if (i < 100) {
            cout << " ";
        }
    }
    return 0;
}
```

## 작은 값으로 따라가기

N=89이면 첫 출력 B, 90부터 100까지는 A입니다. 100점 하나만 입력되면 A 한 개를 출력합니다.

## 복잡도

시간 O(101-N), 추가 공간 O(1).

## 확인 범위

문서의 예시 코드를 로컬 C++17 환경에서 컴파일하고, 문제 예제와 별도 확인 입력을 합해 2건의 출력을 대조했습니다. 비교 시 줄 끝 공백과 마지막 줄바꿈만 무시했습니다. 위 값 변화 설명은 코드 흐름을 수작업으로 추적한 내용입니다. 실행 시간 벤치마크나 코드트리 재제출은 하지 않았습니다.
