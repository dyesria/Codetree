## 현재 풀이와 좋은 점

5부터 17까지 순서대로 출력하며 마지막 공백을 구분합니다.

## 다듬거나 기억할 부분

첫 항 이후에만 공백을 두면 continue와 마지막 값에 대한 중복 if, break를 함께 줄일 수 있습니다. 반복 범위는 그대로 유지됩니다.

## 개선 예시 코드

설명한 개선을 적용한 완전한 Java 실행 코드입니다. 원래 제출 소스는 변경하지 않습니다.

```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        for (int i = 5; i <= 17; ++i) {
            if (i > 5) System.out.print(" ");
            System.out.print(i);
        }
    }
}
```

## 작은 값으로 따라가기

5~17은 17-5+1=13개입니다. 5 앞에는 공백이 없고 6부터 앞 공백을 붙입니다.

## 복잡도

출력 개수가 13개로 고정되어 시간·추가 공간 O(1).

## 확인 범위

문서의 예시 코드를 로컬 Java 21 환경에서 컴파일하고, 문제 예제와 별도 확인 입력을 합해 1건의 출력을 대조했습니다. 비교 시 줄 끝 공백과 마지막 줄바꿈만 무시했습니다. 위 값 변화 설명은 코드 흐름을 수작업으로 추적한 내용입니다. 실행 시간 벤치마크나 코드트리 재제출은 하지 않았습니다.
