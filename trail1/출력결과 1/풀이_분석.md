## 핵심 원리

앞의 두 값을 더하고 이전 값을 한 칸씩 이동시키는 반복입니다. q를 먼저 계산하고 t=s 다음 s=q 순서를 지켜야 합니다.

## 순서대로 따라가기

| 반복 | q | s | t |
|---|---:|---:|---:|
| 시작 | 0 | 1 | 1 |
| 1회 | 2 | 2 | 1 |
| 2회 | 3 | 3 | 2 |
| 3회 | 5 | 5 | 3 |
| 4회 | 8 | 8 | 5 |

출력은 8입니다.

## 기억할 부분

대입 세 줄을 동시 대입으로 보지 말고 위에서 아래로 추적하세요.

## 복습 예시 코드

제시 코드를 C++에서 확인하기 위한 완전한 실행 예시입니다. 필요한 main·출력을 보충하거나 위 설명에 맞게 정리했습니다.

```cpp
#include <iostream>
using namespace std;

int main() {
    int q = 0, s = 1, t = 1;
    for (int i = 0; i < 4; i++) {
        q = s + t;
        t = s;
        s = q;
    }
    cout << q;
    return 0;
}
```

## 복잡도

4회 고정이라 시간·공간 O(1). 반복 횟수 K로 일반화하면 시간 O(K), 추가 공간 O(1).

## 확인 범위

문서의 예시 코드를 로컬 C++17 환경에서 컴파일하고, 복습 확인 입력 1건의 출력을 대조했습니다. 비교 시 줄 끝 공백과 마지막 줄바꿈만 무시했습니다. 위 값 변화 설명은 코드 흐름을 수작업으로 추적한 내용입니다. 실행 시간 벤치마크나 코드트리 재제출은 하지 않았습니다.
