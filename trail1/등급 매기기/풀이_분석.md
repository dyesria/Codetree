## 현재 풀이와 좋은 점

높은 점수부터 else if로 내려가며 해당 등급 하나를 출력합니다.

## 다듬거나 기억할 부분

내림차순 기준 덕분에 80점 조건에서 90점 미만을 다시 적을 필요가 없습니다. 지금처럼 한 분기만 실행하는 구조가 적절합니다.

## 복습 예시 코드

현재 풀이 구조를 유지한 완전한 C++ 실행 코드입니다. 원래 제출 소스는 변경하지 않습니다.

```cpp
#include <iostream>
using namespace std;

int main() {
    int N;
    cin >> N;

    if (N >= 90) {
        cout << "A";
    } else if (N >= 80) {
        cout << "B";
    } else if (N >= 70) {
        cout << "C";
    } else if (N >= 60) {
        cout << "D";
    } else {
        cout << "F";
    }
    
    return 0;
}
```

## 작은 값으로 따라가기

89는 N>=90이 거짓, N>=80이 참이므로 B입니다. 90은 첫 분기에서 A가 됩니다.

## 복잡도

시간·추가 공간 O(1).

## 확인 범위

문서의 예시 코드를 로컬 C++17 환경에서 컴파일하고, 문제 예제와 별도 확인 입력을 합해 2건의 출력을 대조했습니다. 비교 시 줄 끝 공백과 마지막 줄바꿈만 무시했습니다. 위 값 변화 설명은 코드 흐름을 수작업으로 추적한 내용입니다. 실행 시간 벤치마크나 코드트리 재제출은 하지 않았습니다.
