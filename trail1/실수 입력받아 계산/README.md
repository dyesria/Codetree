## 문제

두 실수 $a$, $b$ 를 입력받아 합을 구하여 소수점 아래 둘째자리까지 출력하는 프로그램을 작성해보세요.

## 입력

첫 번째 줄에 실수 $a$가 주어집니다.  

두 번째 줄에 실수 $b$가 주어집니다.

## 제한 조건

- $1 \le a, b \le 100$

## 출력

첫 번째 줄에 실수 $a$와 실수 $b$의 합을 소수점 아래 둘째자리까지 출력합니다.

## 입력 예제

### 예제 1

입력

```text
5.26
3.14
```

출력

```text
8.40
```

• Time Limit: 500 ms

• Memory Limit: 64 MiB
