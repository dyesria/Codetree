## 핵심 원리

i가 1,3,5,7,9로 증가하고, 그중 3의 배수일 때 i-1을 합칩니다.

## 순서대로 따라가기

| i | 3의 배수 | 더하는 값 | 누적합 |
|---|---|---:|---:|
| 1 | 아니요 | 0 | 0 |
| 3 | 예 | 2 | 2 |
| 5 | 아니요 | 0 | 2 |
| 7 | 아니요 | 0 | 2 |
| 9 | 예 | 8 | 10 |

출력은 10입니다.

## 기억할 부분

조건 검사에 사용하는 i와 실제로 더하는 i-1을 구분하세요.

## 복습 예시 코드

제시 코드를 C++에서 확인하기 위한 완전한 실행 예시입니다. 필요한 main·출력을 보충하거나 위 설명에 맞게 정리했습니다.

```cpp
#include <iostream>
using namespace std;

int main() {
    int sum = 0;
    for(int i = 1; i <= 10; i += 2){
        if(i % 3 == 0) {
            sum += i - 1;
        }
    }
    cout << sum << endl;
    return 0;
}
```

## 복잡도

고정 5회라 O(1). 상한 N으로 일반화하면 시간 O(N), 추가 공간 O(1).

## 확인 범위

문서의 예시 코드를 로컬 C++17 환경에서 컴파일하고, 복습 확인 입력 1건의 출력을 대조했습니다. 비교 시 줄 끝 공백과 마지막 줄바꿈만 무시했습니다. 위 값 변화 설명은 코드 흐름을 수작업으로 추적한 내용입니다. 실행 시간 벤치마크나 코드트리 재제출은 하지 않았습니다.
