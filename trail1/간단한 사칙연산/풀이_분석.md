## 현재 풀이와 좋은 점

합·차·정수 몫·나머지를 요구 순서대로 출력합니다.

## 다듬거나 기억할 부분

현재 출력 순서와 계산이 직접적입니다. /는 int끼리 나누는 정수 나눗셈이므로 실수 형변환을 추가하면 의미가 달라집니다.

## 복습 예시 코드

현재 풀이 구조를 유지한 완전한 C++ 실행 코드입니다. 원래 제출 소스는 변경하지 않습니다.

```cpp
#include <iostream>
using namespace std;

int main() {
    int A; int B;

    cin >> A >> B;
    cout << A + B << endl
         << A - B << endl
         << A / B << endl
         << A % B;
    return 0;
}
```

## 작은 값으로 따라가기

A=7,B=3이면 10,4,2,1을 각 줄에 출력합니다.

## 복잡도

시간·추가 공간 O(1).

## 확인 범위

문서의 예시 코드를 로컬 C++17 환경에서 컴파일하고, 문제 예제와 별도 확인 입력을 합해 2건의 출력을 대조했습니다. 비교 시 줄 끝 공백과 마지막 줄바꿈만 무시했습니다. 위 값 변화 설명은 코드 흐름을 수작업으로 추적한 내용입니다. 실행 시간 벤치마크나 코드트리 재제출은 하지 않았습니다.
