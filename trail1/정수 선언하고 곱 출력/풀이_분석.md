## 현재 풀이와 좋은 점

문자열 안의 26과 5를 표시하고 26*5를 계산해 붙입니다.

## 다듬거나 기억할 부분

원문이 두 정수형 변수의 선언과 활용을 요구합니다. 값을 변수에 한 번만 적으면 표시값과 계산값이 서로 어긋날 가능성도 줄어듭니다.

## 개선 예시 코드

설명한 개선을 적용한 완전한 C++ 실행 코드입니다. 원래 제출 소스는 변경하지 않습니다.

```cpp
#include <iostream>
using namespace std;

int main() {
    int a = 26, b = 5;
    cout << a << " * " << b << " = " << a * b;
    return 0;
}
```

## 작은 값으로 따라가기

a=26,b=5 → a*b=130 → 26 * 5 = 130입니다.

## 복잡도

시간·추가 공간 O(1).

## 확인 범위

문서의 예시 코드를 로컬 C++17 환경에서 컴파일하고, 문제 예제와 별도 확인 입력을 합해 1건의 출력을 대조했습니다. 비교 시 줄 끝 공백과 마지막 줄바꿈만 무시했습니다. 위 값 변화 설명은 코드 흐름을 수작업으로 추적한 내용입니다. 실행 시간 벤치마크나 코드트리 재제출은 하지 않았습니다.
