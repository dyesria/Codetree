## 현재 풀이와 좋은 점

A를 기준으로 네 입력과 각각 비교하고 1/0을 출력합니다.

## 다듬거나 기억할 부분

(A>B ? 1 : 0)은 (A>B)만 출력해도 같습니다. C++ bool의 기본 출력이 0과 1이라는 점을 활용하는 가독성 대안입니다.

## 복습 예시 코드

현재 풀이 구조를 유지한 완전한 C++ 실행 코드입니다. 원래 제출 소스는 변경하지 않습니다.

```cpp
#include <iostream>
using namespace std;

int main() {
    int A; int B; int C; int D; int E;

    cin >> A;
    cin >> B >> C >> D >> E;

    cout << (A>B ? 1 : 0) << endl
         << (A>C ? 1 : 0) << endl
         << (A>D ? 1 : 0) << endl
         << (A>E ? 1 : 0) << endl;

    return 0;
}
```

## 작은 값으로 따라가기

A=5, 비교값=3,5,8,1이면 1,0,0,1입니다. 같을 때는 >가 거짓입니다.

## 복잡도

시간·추가 공간 O(1).

## 확인 범위

문서의 예시 코드를 로컬 C++17 환경에서 컴파일하고, 문제 예제와 별도 확인 입력을 합해 1건의 출력을 대조했습니다. 비교 시 줄 끝 공백과 마지막 줄바꿈만 무시했습니다. 위 값 변화 설명은 코드 흐름을 수작업으로 추적한 내용입니다. 실행 시간 벤치마크나 코드트리 재제출은 하지 않았습니다.
