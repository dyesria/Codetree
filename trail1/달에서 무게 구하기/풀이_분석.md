## 현재 풀이와 좋은 점

13에 0.165를 곱하고 소수 여섯 자리로 결과를 출력합니다.

## 다듬거나 기억할 부분

sum은 합계가 아니므로 moonWeight로 바꾸면 의미가 맞습니다. fixed와 precision(6)은 계산 정밀도를 바꾸는 것이 아니라 표시 형식을 정합니다.

## 복습 예시 코드

현재 풀이 구조를 유지한 완전한 C++ 실행 코드입니다. 원래 제출 소스는 변경하지 않습니다.

```cpp
#include <iostream>
#include <iomanip>
using namespace std;

int main() {
    double sum = 13 * 0.165000;

    cout << fixed;
    cout.precision(6);
    cout << "13 * 0.165000 = " << sum;

    return 0;
}
```

## 작은 값으로 따라가기

13×0.165=2.145이며 소수 여섯 자리 형식에서는 2.145000입니다.

## 복잡도

시간·추가 공간 O(1).

## 확인 범위

문서의 예시 코드를 로컬 C++17 환경에서 컴파일하고, 문제 예제와 별도 확인 입력을 합해 1건의 출력을 대조했습니다. 비교 시 줄 끝 공백과 마지막 줄바꿈만 무시했습니다. 위 값 변화 설명은 코드 흐름을 수작업으로 추적한 내용입니다. 실행 시간 벤치마크나 코드트리 재제출은 하지 않았습니다.
