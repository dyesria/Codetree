## 현재 풀이와 좋은 점

100의 배수이지만 400의 배수가 아닌 해를 먼저 건너뛴 뒤 4의 배수를 셉니다. 예외를 우선 처리해 윤년 규칙을 구현했습니다.

## 다듬거나 기억할 부분

반복문 마지막의 else continue는 없어도 다음 반복으로 갑니다. 윤년 조건을 bool로 묶으면 중첩과 continue 없이 읽을 수 있습니다. 선택적 공식 N/4 - N/100 + N/400은 O(1)이며, 빼버린 400의 배수를 다시 더하는 원리입니다.

## 개선 예시 코드

설명한 개선을 적용한 완전한 C++ 실행 코드입니다. 원래 제출 소스는 변경하지 않습니다.

```cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;
    int count = 0;
    for (int year = 1; year <= n; ++year) {
        bool leap = year % 4 == 0 &&
                    (year % 100 != 0 || year % 400 == 0);
        if (leap) ++count;
    }
    cout << count;
    return 0;
}
```

## 작은 값으로 따라가기

N=100이면 4의 배수 25개에서 100을 빼 24개입니다. N=400이면 100 - 4 + 1 = 97개입니다.

## 복잡도

현재·아래 반복 예시: 시간 O(N), 추가 공간 O(1). 공식 대안: 시간·공간 O(1).

## 확인 범위

문서의 예시 코드를 로컬 C++17 환경에서 컴파일하고, 문제 예제와 별도 확인 입력을 합해 5건의 출력을 대조했습니다. 비교 시 줄 끝 공백과 마지막 줄바꿈만 무시했습니다. 위 값 변화 설명은 코드 흐름을 수작업으로 추적한 내용입니다. 실행 시간 벤치마크나 코드트리 재제출은 하지 않았습니다.
