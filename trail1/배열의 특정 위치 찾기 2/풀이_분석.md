## 현재 풀이와 좋은 점

입력 순번 i의 홀짝에 따라 두 합을 누적하고 큰 합에서 작은 합을 뺍니다.

## 다듬거나 기억할 부분

값 N의 홀짝이 아니라 위치 i의 홀짝을 검사한 점이 핵심입니다. 차이를 절댓값 함수로 줄일 수 있지만 현재 분기도 명확합니다.

## 복습 예시 코드

현재 풀이 구조를 유지한 완전한 C++ 실행 코드입니다. 원래 제출 소스는 변경하지 않습니다.

```cpp
#include <iostream>
using namespace std;

int main() {
    int oddSum = 0;
    int evenSum = 0;
    int N;

    for (int i=1; i<=10; i++) {
        cin >> N;
        if (i % 2 == 0) {
            evenSum += N;
        } else {
            oddSum += N;
        }
    }

    if (evenSum >= oddSum) {
        cout << evenSum - oddSum;
    } else {
        cout << oddSum - evenSum;
    }
     
    return 0;
}
```

## 작은 값으로 따라가기

1~10을 넣으면 홀수 위치 합 1+3+5+7+9=25, 짝수 위치 합 30이므로 차이 5입니다.

## 복잡도

고정 10개라 시간·추가 공간 O(1). K개로 일반화하면 시간 O(K), 추가 공간 O(1).

## 확인 범위

문서의 예시 코드를 로컬 C++17 환경에서 컴파일하고, 문제 예제와 별도 확인 입력을 합해 1건의 출력을 대조했습니다. 비교 시 줄 끝 공백과 마지막 줄바꿈만 무시했습니다. 위 값 변화 설명은 코드 흐름을 수작업으로 추적한 내용입니다. 실행 시간 벤치마크나 코드트리 재제출은 하지 않았습니다.
