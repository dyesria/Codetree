## 현재 풀이와 좋은 점

두 과목 모두 A가 높을 때만 1을 출력합니다.

## 다듬거나 기억할 부분

&&를 사용해 '두 과목 모두'를 표현했습니다. (조건 ? 1 : 0)은 조건만 출력해도 같은 값이지만 현재 코드도 명확합니다.

## 복습 예시 코드

현재 풀이 구조를 유지한 완전한 C++ 실행 코드입니다. 원래 제출 소스는 변경하지 않습니다.

```cpp
#include <iostream>
using namespace std;

int main() {
    int AMath; int AEng;
    int BMath; int BEng;

    cin >> AMath >> AEng;
    cin >> BMath >> BEng;

    cout << (AMath > BMath && AEng > BEng ? 1 : 0) << endl;
    return 0;
}
```

## 작은 값으로 따라가기

수학 A=90,B=80,영어 A=70,B=75면 영어에서 실패해 0입니다.

## 복잡도

시간·추가 공간 O(1).

## 확인 범위

문서의 예시 코드를 로컬 C++17 환경에서 컴파일하고, 문제 예제와 별도 확인 입력을 합해 2건의 출력을 대조했습니다. 비교 시 줄 끝 공백과 마지막 줄바꿈만 무시했습니다. 위 값 변화 설명은 코드 흐름을 수작업으로 추적한 내용입니다. 실행 시간 벤치마크나 코드트리 재제출은 하지 않았습니다.
