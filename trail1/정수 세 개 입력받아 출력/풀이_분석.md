## 현재 풀이와 좋은 점

세 정수를 차례로 읽어 같은 순서로 공백을 두고 출력합니다.

## 다듬거나 기억할 부분

현재 입력 순서와 출력 순서가 일치합니다. 배열이나 반복문을 도입할 만큼 반복이 크지 않습니다.

## 복습 예시 코드

현재 풀이 구조를 유지한 완전한 C++ 실행 코드입니다. 원래 제출 소스는 변경하지 않습니다.

```cpp
#include <iostream>
using namespace std;

int main() {
    int a; int b; int c;
    cin >> a >> b >> c;

    cout << a << " " << b << " " << c; 
    return 0;
}
```

## 작은 값으로 따라가기

1,2,3을 읽으면 1 2 3입니다. 문자열 연결 123과 구분하세요.

## 복잡도

시간·추가 공간 O(1).

## 확인 범위

문서의 예시 코드를 로컬 C++17 환경에서 컴파일하고, 문제 예제와 별도 확인 입력을 합해 1건의 출력을 대조했습니다. 비교 시 줄 끝 공백과 마지막 줄바꿈만 무시했습니다. 위 값 변화 설명은 코드 흐름을 수작업으로 추적한 내용입니다. 실행 시간 벤치마크나 코드트리 재제출은 하지 않았습니다.
