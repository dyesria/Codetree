## 문제

$10$개의 문자를 입력받아서 두 번째, 다섯 번째, 여덟 번째 입력받은 문자를 차례로 출력하는 프로그램을 작성해보세요.

## 입력

$10$개의 문자가 공백을 사이에 두고 차례로 입력됩니다.

## 출력

주어지는 문자중 두 번째, 다섯 번째, 여덟 번째 문자를 차례로 공백을 사이에 두고 출력합니다.

## 입력 예제

### 예제 1

입력

```text
L E B R O S C O D E
```

출력

```text
E O O
```
