## 핵심 원리

a%(a%b)에서 나눗셈의 제수 역할을 하는 값은 a%b입니다. 이것이 0이면 C++ 정수 나머지 연산은 정의되지 않은 동작입니다.

## 순서대로 따라가기

보기의 a=10,b=5에서 10%5=0이 되어 다음 연산이 10%0이 됩니다. 따라서 해당 보기가 문제 상황입니다.

## 기억할 부분

b가 0인지 먼저 확인하고, 이어 a%b가 0인지 확인해야 합니다. 아래는 위험한 연산을 실행하지 않는 안전한 복습 예시입니다. Java의 예외와 JavaScript의 NaN처럼 언어별 동작을 C++와 동일하다고 단정하지 마세요.

## 복습 예시 코드

제시 코드를 C++에서 확인하기 위한 완전한 실행 예시입니다. 필요한 main·출력을 보충하거나 위 설명에 맞게 정리했습니다.

```cpp
#include <iostream>
using namespace std;

int main() {
    int a = 10, b = 5;
    if (b == 0) {
        cout << "first divisor is zero";
    } else {
        int remainder = a % b;
        if (remainder == 0) cout << "second divisor is zero";
        else cout << a % b << ' ' << a % remainder;
    }
    return 0;
}
```

## 복잡도

시간·공간 O(1).

## 확인 범위

문서의 예시 코드를 로컬 C++17 환경에서 컴파일하고, 복습 확인 입력 1건의 출력을 대조했습니다. 비교 시 줄 끝 공백과 마지막 줄바꿈만 무시했습니다. 위 값 변화 설명은 코드 흐름을 수작업으로 추적한 내용입니다. 실행 시간 벤치마크나 코드트리 재제출은 하지 않았습니다.
