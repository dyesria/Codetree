## 현재 풀이와 좋은 점

4의 배수인지 확인한 뒤 세기 예외를 중첩 조건으로 처리합니다. 400의 배수를 윤년으로 남겨 두었습니다.

## 다듬거나 기억할 부분

윤년의 전체 조건을 bool 한 개로 표현하면 같은 false 출력의 중복이 줄어듭니다. 성능 최적화보다 규칙을 한눈에 읽는 개선입니다.

## 개선 예시 코드

설명한 개선을 적용한 완전한 C++ 실행 코드입니다. 원래 제출 소스는 변경하지 않습니다.

```cpp
#include <iostream>
using namespace std;

int main() {
    int year;
    cin >> year;
    bool leap = year % 4 == 0 &&
                (year % 100 != 0 || year % 400 == 0);
    cout << (leap ? "true" : "false");
    return 0;
}
```

## 작은 값으로 따라가기

1900은 100의 배수지만 400의 배수가 아니므로 false, 2000은 400의 배수이므로 true입니다.

## 복잡도

시간·추가 공간 O(1).

## 확인 범위

문서의 예시 코드를 로컬 C++17 환경에서 컴파일하고, 문제 예제와 별도 확인 입력을 합해 2건의 출력을 대조했습니다. 비교 시 줄 끝 공백과 마지막 줄바꿈만 무시했습니다. 위 값 변화 설명은 코드 흐름을 수작업으로 추적한 내용입니다. 실행 시간 벤치마크나 코드트리 재제출은 하지 않았습니다.
