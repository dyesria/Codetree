## 문제

두 정수 $a$와 $b$를 입력 받은 후, $a$와 $b$를 곱한 값을 출력하는 프로그램을 작성해보세요.

## 입력

첫 줄에 두 정수 $a$와 $b$가 공백으로 구분되어 주어집니다.

## 제한 조건

- $1 \le a \le 100$
- $1 \le b \le 100$

## 출력

첫 줄에 $a$와 $b$를 곱한 값을 출력합니다.

## 입력 예제

### 예제 1

입력

```text
3 2
```

출력

```text
6
```

### 예제 2

입력

```text
13 17
```

출력

```text
221
```

• Time Limit: 500 ms

• Memory Limit: 64 MiB
