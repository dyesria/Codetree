## 현재 풀이가 하는 일

1부터 N까지 검사하면서 3의 배수, 십의 자리, 일의 자리 조건을 차례로 확인합니다. `i >= 30`일 때와 아닐 때를 나누어 같은 출력 조건을 반복합니다.

**잘한 점:** 10, 20처럼 일의 자리가 0인 수를 3·6·9로 잘못 취급하지 않도록 별도로 처리했습니다. 마지막 숫자 뒤의 공백도 구분했습니다.

## 다듬을 부분

문제의 N은 100 이하이므로 현재 분기 방식은 이 범위에 맞춰져 있습니다. 다만 `i % 30 < 10`이 30\~39, 60\~69, 90\~99를 뜻한다는 점을 바로 읽기 어렵고, 두 분기의 출력 코드가 중복됩니다.

'3의 배수인가'와 '3·6·9가 들어 있는가'를 이름 있는 조건으로 분리하면 규칙을 그대로 읽을 수 있습니다. 아래 예시는 **가독성과 범위 확장**을 위한 대안입니다. 현재 작은 입력에서 더 빠르다고 주장하는 최적화는 아닙니다.

## 개선 예시 코드

완전한 C++ 실행 코드입니다. 사용자 소스 파일은 변경하지 않습니다.

```cpp
#include <iostream>
using namespace std;

bool contains369(int number) {
    while (number > 0) {
        int digit = number % 10;
        if (digit == 3 || digit == 6 || digit == 9) {
            return true;
        }
        number /= 10;
    }
    return false;
}

int main() {
    int n;
    cin >> n;

    for (int number = 1; number <= n; ++number) {
        if (number > 1) cout << ' ';
        bool clap = number % 3 == 0 || contains369(number);
        cout << (clap ? 0 : number);
    }
    return 0;
}
```

## 왜 이렇게 동작하나요?

`% 10`은 마지막 자리를 꺼내고, `/ 10`은 그 자리를 지웁니다. 3·6·9를 찾는 순간 true를 반환합니다. 출력은 마지막에 한 번만 합니다.

| 검사할 수 | 3의 배수 | 자릿수 확인 | 출력 |
|---|---|---|---|
| 10 | 아니요 | 0, 1 모두 해당 없음 | 10 |
| 13 | 아니요 | 일의 자리 3 | 0 |
| 31 | 아니요 | 1을 지우면 3 | 0 |
| 42 | 예 | 추가 검사 불필요 | 0 |
| 100 | 아니요 | 0, 0, 1 모두 해당 없음 | 100 |

## 복잡도와 확인 포인트

현재 코드는 수마다 고정된 조건을 확인하므로 시간 O(N), 추가 공간 O(1)입니다. 예시는 자릿수를 D라고 하면 O(ND), 추가 공간 O(1)이며, 현재 제한에서는 D가 최대 3입니다.

문서의 예시 코드를 로컬 C++17 환경에서 컴파일하고, 문제 예제와 별도 확인 입력을 합해 4건의 출력을 대조했습니다. 비교 시 줄 끝 공백과 마지막 줄바꿈만 무시했습니다. 위 값 변화 설명은 코드 흐름을 수작업으로 추적한 내용입니다. 실행 시간 벤치마크나 코드트리 재제출은 하지 않았습니다.

**기억할 점:** 예외 분기를 늘리기 전에 문제의 두 규칙을 각각 하나의 조건으로 표현해 보세요.
