## 현재 풀이와 좋은 점

수학이 같으면 영어를, 다르면 수학을 비교해 이름을 결정합니다. 우선순위를 분리했습니다.

## 다듬거나 기억할 부분

삼항 연산자 양쪽에서 각각 name에 대입하기보다 name=(조건?'A':'B') 형태가 더 직접적입니다. 아래는 수학 우선·동점 시 영어 우선 규칙을 한 bool로 표현합니다.

## 개선 예시 코드

설명한 개선을 적용한 완전한 C++ 실행 코드입니다. 원래 제출 소스는 변경하지 않습니다.

```cpp
#include <iostream>
using namespace std;

int main() {
    int aMath, aEnglish, bMath, bEnglish;
    cin >> aMath >> aEnglish >> bMath >> bEnglish;
    bool aWins = aMath > bMath ||
                 (aMath == bMath && aEnglish >= bEnglish);
    cout << (aWins ? 'A' : 'B');
    return 0;
}
```

## 작은 값으로 따라가기

수학이 둘 다 90일 때 영어 A=80,B=85이면 B입니다. 수학 A가 더 높으면 영어와 관계없이 A입니다.

## 복잡도

시간·추가 공간 O(1).

## 확인 범위

문서의 예시 코드를 로컬 C++17 환경에서 컴파일하고, 문제 예제와 별도 확인 입력을 합해 2건의 출력을 대조했습니다. 비교 시 줄 끝 공백과 마지막 줄바꿈만 무시했습니다. 위 값 변화 설명은 코드 흐름을 수작업으로 추적한 내용입니다. 실행 시간 벤치마크나 코드트리 재제출은 하지 않았습니다.
