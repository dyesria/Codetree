## 문제

$0$일을 기점으로 $2$일마다 교실 청소를, $3$일마다 복도 청소를, $12$일마다 화장실 청소를 합니다. 날짜가 겹치는 날에는 주기가 더 긴 것을 하기로 했습니다. $n$일간 진행했을 때 각 장소의 청소 횟수를 차례로 출력하는 프로그램을 작성해주세요. 단, 시작 날인 $0$일에는 청소를 진행하지 않습니다.

## 입력

첫 번째 줄에 정수 $n$이 주어집니다.

## 제한 조건

- $1 \le n \le 1,000$

## 출력

교실 청소 횟수, 복도 청소 횟수, 화장실 청소의 횟수를 차례로 공백을 사이에 두고 출력합니다.

## 입력 예제

### 예제 1

입력

```text
11
```

출력

```text
4 3 0
```

### 예제 2

입력

```text
24
```

출력

```text
8 6 2
```
