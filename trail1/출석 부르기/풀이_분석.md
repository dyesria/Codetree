## 현재 풀이와 좋은 점

번호 1~3에 이름을 대응시키고 그 외는 Vacancy를 출력합니다.

## 다듬거나 기억할 부분

배타적인 값 비교라 현재 else if가 명확합니다. 이름 목록이 크게 늘어날 때만 배열이나 표 기반 표현을 고려하면 됩니다.

## 복습 예시 코드

현재 풀이 구조를 유지한 완전한 C++ 실행 코드입니다. 원래 제출 소스는 변경하지 않습니다.

```cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;

    if(n == 1) {
        cout << "John";
    } else if(n == 2) {
        cout << "Tom";
    } else if(n == 3) {
        cout << "Paul";
    } else {
        cout << "Vacancy";
    }


    return 0;
}
```

## 작은 값으로 따라가기

1→John, 2→Tom, 3→Paul, 4→Vacancy입니다.

## 복잡도

시간·추가 공간 O(1).

## 확인 범위

문서의 예시 코드를 로컬 C++17 환경에서 컴파일하고, 문제 예제와 별도 확인 입력을 합해 2건의 출력을 대조했습니다. 비교 시 줄 끝 공백과 마지막 줄바꿈만 무시했습니다. 위 값 변화 설명은 코드 흐름을 수작업으로 추적한 내용입니다. 실행 시간 벤치마크나 코드트리 재제출은 하지 않았습니다.
