## 핵심 원리

b와 c가 int이므로 b/c에서 정수 나눗셈이 먼저 일어납니다. float a에 대입해도 버린 소수부는 되살아나지 않습니다.

## 순서대로 따라가기

3/2 → 정수 1 → float 1.0 → 소수 한 자리 출력 1.0입니다.

## 기억할 부분

1.5가 필요하다면 나누기 전에 static_cast<double>(b)/c로 바꿔야 합니다. 이 대안은 원문 출력과 다른 계산을 의도할 때만 사용합니다.

## 복습 예시 코드

제시 코드를 C++에서 확인하기 위한 완전한 실행 예시입니다. 필요한 main·출력을 보충하거나 위 설명에 맞게 정리했습니다.

```cpp
#include <iostream>
using namespace std;

int main() {
    float a;
    int b = 3, c = 2;
    a = b / c;
    cout << fixed;
    cout.precision(1);
    cout << a;
    return 0;
}
```

## 복잡도

시간·공간 O(1).

## 확인 범위

문서의 예시 코드를 로컬 C++17 환경에서 컴파일하고, 복습 확인 입력 1건의 출력을 대조했습니다. 비교 시 줄 끝 공백과 마지막 줄바꿈만 무시했습니다. 위 값 변화 설명은 코드 흐름을 수작업으로 추적한 내용입니다. 실행 시간 벤치마크나 코드트리 재제출은 하지 않았습니다.
