## 문제

$A, B$ 두 자연수를 입력받아 $A$부터 $B$까지의 합을 구해 출력하는 프로그램을 작성해보세요.

## 입력

첫 번째 줄에 정수 $A, B$가 공백을 사이에 두고 주어집니다.

## 제한 조건

- $1 \le A \le B \le 100$

## 출력

첫 번째 줄에 $A$부터 $B$까지의 합을 출력합니다.

## 입력 예제

### 예제 1

입력

```text
2 5
```

출력

```text
14
```

### 예제 2

입력

```text
5 5
```

출력

```text
5
```

• Time Limit: 500 ms
