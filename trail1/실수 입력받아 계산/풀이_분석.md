## 현재 풀이와 좋은 점

두 double을 더한 뒤 소수 두 자리로 표시합니다.

## 다듬거나 기억할 부분

실수 합을 계산한 후 마지막에 출력 형식을 적용하는 순서가 적절합니다. 각 입력을 먼저 반올림해 더하면 다른 결과가 나올 수 있습니다.

## 복습 예시 코드

현재 풀이 구조를 유지한 완전한 C++ 실행 코드입니다. 원래 제출 소스는 변경하지 않습니다.

```cpp
#include <iostream>
using namespace std;

int main() {
    double a; double b;

    cin >> a >> b;
    cout << fixed;
    cout.precision(2);

    cout << a+b;
    return 0;
}
```

## 작은 값으로 따라가기

1.25와 2.50의 합은 3.75입니다.

## 복잡도

시간·추가 공간 O(1).

## 확인 범위

문서의 예시 코드를 로컬 C++17 환경에서 컴파일하고, 문제 예제와 별도 확인 입력을 합해 1건의 출력을 대조했습니다. 비교 시 줄 끝 공백과 마지막 줄바꿈만 무시했습니다. 위 값 변화 설명은 코드 흐름을 수작업으로 추적한 내용입니다. 실행 시간 벤치마크나 코드트리 재제출은 하지 않았습니다.
