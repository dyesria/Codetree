## 핵심 원리

else는 가장 가까운 아직 짝이 없는 if(y>10)에 연결됩니다. 마지막 C 출력은 바깥 if에도 속하지 않습니다.

## 순서대로 따라가기

x=9라 첫 조건 참, y=11이라 안쪽 조건도 참이어서 A를 출력합니다. 이후 C를 출력하므로 결과는 AC입니다.

## 기억할 부분

중괄호를 명시하면 들여쓰기만 보고 else를 잘못 연결하는 실수를 줄일 수 있습니다. 아래 예시는 의미를 유지하면서 괄호를 보충했습니다.

## 복습 예시 코드

제시 코드를 C++에서 확인하기 위한 완전한 실행 예시입니다. 필요한 main·출력을 보충하거나 위 설명에 맞게 정리했습니다.

```cpp
#include <iostream>
using namespace std;

int main() {
    int x = 9, y = 11;
    if (x < 10) {
        if (y > 10) cout << "A";
        else cout << "B";
    }
    cout << "C";
    return 0;
}
```

## 복잡도

시간·공간 O(1).

## 확인 범위

문서의 예시 코드를 로컬 C++17 환경에서 컴파일하고, 복습 확인 입력 1건의 출력을 대조했습니다. 비교 시 줄 끝 공백과 마지막 줄바꿈만 무시했습니다. 위 값 변화 설명은 코드 흐름을 수작업으로 추적한 내용입니다. 실행 시간 벤치마크나 코드트리 재제출은 하지 않았습니다.
