## 핵심 원리

fixed와 precision(2)는 소수 이하 두 자리를 표시합니다.

## 순서대로 따라가기

2.8437에서 셋째 소수 자리는 3이므로 표시 결과는 2.84입니다.

## 기억할 부분

precision(2)만 지정한 일반 부동소수점 출력의 유효 숫자 개수와 fixed의 소수 자릿수를 구분하세요.

## 복습 예시 코드

제시 코드를 C++에서 확인하기 위한 완전한 실행 예시입니다. 필요한 main·출력을 보충하거나 위 설명에 맞게 정리했습니다.

```cpp
#include <iostream>
using namespace std;

int main() {
    cout << fixed;
    double a = 2.8437;
    cout.precision(2);
    cout << a << endl;
    return 0;
}
```

## 복잡도

시간·공간 O(1).

## 확인 범위

문서의 예시 코드를 로컬 C++17 환경에서 컴파일하고, 복습 확인 입력 1건의 출력을 대조했습니다. 비교 시 줄 끝 공백과 마지막 줄바꿈만 무시했습니다. 위 값 변화 설명은 코드 흐름을 수작업으로 추적한 내용입니다. 실행 시간 벤치마크나 코드트리 재제출은 하지 않았습니다.
