## 현재 풀이와 좋은 점

홀수면 3을 더한 뒤 바뀐 값이 3의 배수인지 다시 확인합니다.

## 다듬거나 기억할 부분

두 if가 순차적으로 적용되는 것이 핵심입니다. else if로 바꾸면 첫 연산 뒤의 두 번째 연산이 생략됩니다.

## 복습 예시 코드

현재 풀이 구조를 유지한 완전한 C++ 실행 코드입니다. 원래 제출 소스는 변경하지 않습니다.

```cpp
#include <iostream>
using namespace std;

int main() {
    int A;
    cin >> A;

    if (A % 2 != 0) {
        A += 3;
    }

    if (A % 3 == 0) {
        A /= 3;
    }

    cout << A;
    return 0;
}
```

## 작은 값으로 따라가기

3 → 홀수이므로 6 → 3의 배수이므로 2입니다. 4는 두 조건에 모두 해당하지 않아 4입니다.

## 복잡도

시간·추가 공간 O(1).

## 확인 범위

문서의 예시 코드를 로컬 C++17 환경에서 컴파일하고, 문제 예제와 별도 확인 입력을 합해 2건의 출력을 대조했습니다. 비교 시 줄 끝 공백과 마지막 줄바꿈만 무시했습니다. 위 값 변화 설명은 코드 흐름을 수작업으로 추적한 내용입니다. 실행 시간 벤치마크나 코드트리 재제출은 하지 않았습니다.
