## 현재 풀이와 좋은 점

3 또는 5로 나눈 나머지 중 하나라도 0이면 1을 출력합니다.

## 다듬거나 기억할 부분

현재 OR 조건이 문제 문장과 일치합니다. 같은 조건으로 두 번 출력하지 않고 한 번만 결과를 내는 점을 유지하세요.

## 복습 예시 코드

현재 풀이 구조를 유지한 완전한 C++ 실행 코드입니다. 원래 제출 소스는 변경하지 않습니다.

```cpp
#include <iostream>
using namespace std;

int main() {
    int A;
    cin >> A;

    if (A % 3 == 0 || A % 5 == 0) {
        cout << "1";
    } else {
        cout << "0";
    }
    return 0;
}
```

## 작은 값으로 따라가기

15는 양쪽에 해당하지만 결과는 1 하나입니다. 7은 모두 거짓이어서 0입니다.

## 복잡도

시간·추가 공간 O(1).

## 확인 범위

문서의 예시 코드를 로컬 C++17 환경에서 컴파일하고, 문제 예제와 별도 확인 입력을 합해 2건의 출력을 대조했습니다. 비교 시 줄 끝 공백과 마지막 줄바꿈만 무시했습니다. 위 값 변화 설명은 코드 흐름을 수작업으로 추적한 내용입니다. 실행 시간 벤치마크나 코드트리 재제출은 하지 않았습니다.
