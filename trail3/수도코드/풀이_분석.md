## 핵심 원리

바깥 반복 0\~5는 6회, 안쪽 반복 0\~4는 5회입니다. 각 조합마다 x를 1 늘립니다.

## 순서대로 따라가기

바깥 반복이 한 번 끝날 때마다 x는 5,10,15,20,25,30이 됩니다. 최종 출력은 30입니다.

## 기억할 부분

<=5와 <5의 반복 횟수 차이를 구분하세요. 중첩 반복에서는 횟수를 더하지 않고 곱합니다.

## 복습 예시 코드

제시 코드를 C++에서 확인하기 위한 완전한 실행 예시입니다. 필요한 main·출력을 보충하거나 위 설명에 맞게 정리했습니다.

```cpp
#include <iostream>
using namespace std;

int main() {
    int x = 0;
    for (int i = 0; i <= 5; ++i) {
        for (int j = 0; j < 5; ++j) ++x;
    }
    cout << x;
    return 0;
}
```

## 복잡도

고정 범위에서는 O(1). 바깥 N회·안쪽 M회라면 시간 O(NM), 추가 공간 O(1).

## 확인 범위

문서의 예시 코드를 로컬 C++17 환경에서 컴파일하고, 복습 확인 입력 1건의 출력을 대조했습니다. 비교 시 줄 끝 공백과 마지막 줄바꿈만 무시했습니다. 위 값 변화 설명은 코드 흐름을 수작업으로 추적한 내용입니다. 실행 시간 벤치마크나 코드트리 재제출은 하지 않았습니다.
