## 문제

두 정수를 입력받아서 나눈 몫과 나머지를 출력하는 프로그램을 작성해주세요.

## 입력

첫 번째 줄에 정수 $A, B$가 공백을 사이에 두고 주어집니다.

## 제한 조건

- $1 \le A, B \le 100$

## 출력

두 정수의 몫과 나머지를 순서대로 출력하되 사이에 `...`를 포함합니다.

## 입력 예제

### 예제 1

입력

```text
56 10
```

출력

```text
5...6
```

• Time Limit: 500 ms

• Memory Limit: 64 MiB
