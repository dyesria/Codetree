## 현재 풀이와 좋은 점

N부터 100까지의 수를 sum에 누적합니다. 합을 0으로 초기화하고 양 끝을 포함한 점이 정확합니다.

## 다듬거나 기억할 부분

반복문을 연습하는 풀이로 충분합니다. 선택적 수학 대안은 (N + 100) * (101 - N) / 2입니다. 항의 개수는 100 - N + 1이므로 +1을 빠뜨리지 않아야 합니다. 공식은 시간 O(1)이지만 반복문 연습 목적에는 현재 방식이 자연스럽습니다.

## 복습 예시 코드

현재 풀이 구조를 유지한 완전한 C++ 실행 코드입니다. 원래 제출 소스는 변경하지 않습니다.

```cpp
#include <iostream>
using namespace std;

int main() {
    int N;
    int sum = 0;
    cin >> N;

    for (int i=N; i<=100; i++) {
        sum += i;
    }

    cout << sum;
    return 0;
}
```

## 작은 값으로 따라가기

N=98이면 sum은 0 → 98 → 197 → 297입니다. N=100일 때도 한 번 더해 100이 됩니다.

## 복잡도

시간 O(101-N), 추가 공간 O(1).

## 확인 범위

문서의 예시 코드를 로컬 C++17 환경에서 컴파일하고, 문제 예제와 별도 확인 입력을 합해 1건의 출력을 대조했습니다. 비교 시 줄 끝 공백과 마지막 줄바꿈만 무시했습니다. 위 값 변화 설명은 코드 흐름을 수작업으로 추적한 내용입니다. 실행 시간 벤치마크나 코드트리 재제출은 하지 않았습니다.
