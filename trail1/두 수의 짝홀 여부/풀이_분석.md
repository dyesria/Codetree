## 현재 풀이와 좋은 점

두 입력 각각의 나머지를 확인해 even 또는 odd를 출력합니다.

## 다듬거나 기억할 부분

두 입력뿐이라 현재 반복된 if도 충분히 읽힙니다. 같은 판단을 여러 곳에서 재사용할 때만 parity(value) 함수로 묶으면 됩니다.

## 복습 예시 코드

현재 풀이 구조를 유지한 완전한 C++ 실행 코드입니다. 원래 제출 소스는 변경하지 않습니다.

```cpp
#include <iostream>
using namespace std;

int main() {
    int a; int b;
 
    cin >> a >> b;

    if (a % 2 == 0) {
        cout << "even" << endl;
    } else {
        cout << "odd" << endl;
    }

    if (b % 2 == 0) {
        cout << "even" << endl;
    } else {
        cout << "odd" << endl;
    }
    return 0;
}
```

## 작은 값으로 따라가기

2와 3이면 첫 줄 even, 두 번째 줄 odd입니다. a의 결과가 b의 판단에 영향을 주지 않습니다.

## 복잡도

시간·추가 공간 O(1).

## 확인 범위

문서의 예시 코드를 로컬 C++17 환경에서 컴파일하고, 문제 예제와 별도 확인 입력을 합해 2건의 출력을 대조했습니다. 비교 시 줄 끝 공백과 마지막 줄바꿈만 무시했습니다. 위 값 변화 설명은 코드 흐름을 수작업으로 추적한 내용입니다. 실행 시간 벤치마크나 코드트리 재제출은 하지 않았습니다.
