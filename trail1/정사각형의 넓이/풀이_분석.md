## 현재 풀이와 좋은 점

한 변을 제곱해 넓이를 출력하고 변이 5 미만이면 tiny를 덧붙입니다.

## 다듬거나 기억할 부분

넓이 출력과 조건부 안내를 분리한 구조가 좋습니다. tiny 조건은 넓이가 아니라 입력 변 길이 N에 대한 비교입니다.

## 복습 예시 코드

현재 풀이 구조를 유지한 완전한 C++ 실행 코드입니다. 원래 제출 소스는 변경하지 않습니다.

```cpp
#include <iostream>
using namespace std;

int main() {
    int N;

    cin >> N;

    cout << N * N << endl;
    
    if (N < 5) {
        cout << "tiny";
    }

    
    return 0;
}
```

## 작은 값으로 따라가기

N=4이면 16 다음 줄 tiny, N=5이면 25만 출력합니다.

## 복잡도

시간·추가 공간 O(1).

## 확인 범위

문서의 예시 코드를 로컬 C++17 환경에서 컴파일하고, 문제 예제와 별도 확인 입력을 합해 2건의 출력을 대조했습니다. 비교 시 줄 끝 공백과 마지막 줄바꿈만 무시했습니다. 위 값 변화 설명은 코드 흐름을 수작업으로 추적한 내용입니다. 실행 시간 벤치마크나 코드트리 재제출은 하지 않았습니다.
