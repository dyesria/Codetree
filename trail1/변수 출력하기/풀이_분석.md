## 현재 풀이와 좋은 점

변수 a,b 사이에 ...를 넣어 출력합니다.

## 다듬거나 기억할 부분

C 한 글자는 char로 나타낼 수 있습니다. 출력 형식과 변수 사용이라는 학습 목표를 현재처럼 분리해 두면 좋습니다.

## 복습 예시 코드

현재 풀이 구조를 유지한 완전한 C++ 실행 코드입니다. 원래 제출 소스는 변경하지 않습니다.

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    int a = 3;
    string b = "C";

    cout << a << "..." << b;
    
    return 0;
}
```

## 작은 값으로 따라가기

a=3,b=C를 차례로 출력하면 3...C입니다.

## 복잡도

시간·추가 공간 O(1).

## 확인 범위

문서의 예시 코드를 로컬 C++17 환경에서 컴파일하고, 문제 예제와 별도 확인 입력을 합해 1건의 출력을 대조했습니다. 비교 시 줄 끝 공백과 마지막 줄바꿈만 무시했습니다. 위 값 변화 설명은 코드 흐름을 수작업으로 추적한 내용입니다. 실행 시간 벤치마크나 코드트리 재제출은 하지 않았습니다.
