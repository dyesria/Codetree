## 현재 풀이와 좋은 점

중간 점수가 90 미만이면 먼저 제외하고 기말 점수에 따라 장학금을 결정합니다.

## 다듬거나 기억할 부분

필수 조건을 먼저 처리하여 이후 분기가 기말 점수만 보게 만든 구조가 좋습니다. 기말 95 이상을 90 이상보다 먼저 검사해야 합니다.

## 복습 예시 코드

현재 풀이 구조를 유지한 완전한 C++ 실행 코드입니다. 원래 제출 소스는 변경하지 않습니다.

```cpp
#include <iostream>
using namespace std;

int main() {
    int mScore; int fScore;
    cin >> mScore >> fScore;

    if (mScore < 90) {
        cout << "0";
    } else if (95 <= fScore) {
        cout << "100000";
    } else if (90 <= fScore) {
        cout << "50000";
    } else {
        cout << "0";
    }

    return 0;
}
```

## 작은 값으로 따라가기

중간 89·기말 100은 0, 중간 90·기말 94는 50000, 기말 95는 100000입니다.

## 복잡도

시간·추가 공간 O(1).

## 확인 범위

문서의 예시 코드를 로컬 C++17 환경에서 컴파일하고, 문제 예제와 별도 확인 입력을 합해 2건의 출력을 대조했습니다. 비교 시 줄 끝 공백과 마지막 줄바꿈만 무시했습니다. 위 값 변화 설명은 코드 흐름을 수작업으로 추적한 내용입니다. 실행 시간 벤치마크나 코드트리 재제출은 하지 않았습니다.
