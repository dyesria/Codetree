## 현재 풀이와 좋은 점

PrintWords가 N번 같은 문자열을 출력합니다. 반복 출력을 함수로 분리해 문제의 함수 학습 목표를 지켰습니다.

## 다듬거나 기억할 부분

전역 N은 필요하지 않습니다. main에서 읽은 지역변수를 인자로 전달하면 함수가 필요한 데이터가 분명해집니다. 함수 매개변수와 전역변수가 같은 이름인 혼동도 사라집니다.

## 개선 예시 코드

설명한 개선을 적용한 완전한 C++ 실행 코드입니다. 원래 제출 소스는 변경하지 않습니다.

```cpp
#include <iostream>
using namespace std;

void printWords(int count) {
    for (int i = 0; i < count; ++i) {
        cout << "12345^&*()_\n";
    }
}

int main() {
    int n;
    cin >> n;
    printWords(n);
    return 0;
}
```

## 작은 값으로 따라가기

N=2이면 함수의 반복이 두 번 실행되어 문자열이 두 줄 출력됩니다.

## 복잡도

시간 O(N), 추가 공간 O(1).

## 확인 범위

문서의 예시 코드를 로컬 C++17 환경에서 컴파일하고, 문제 예제와 별도 확인 입력을 합해 1건의 출력을 대조했습니다. 비교 시 줄 끝 공백과 마지막 줄바꿈만 무시했습니다. 위 값 변화 설명은 코드 흐름을 수작업으로 추적한 내용입니다. 실행 시간 벤치마크나 코드트리 재제출은 하지 않았습니다.
