## 현재 풀이와 좋은 점

날짜를 순회하며 교실·복도·화장실 중 한 장소에 횟수를 더합니다. 장소별 집계 변수를 둔 점이 읽기 좋습니다.

## 다듬거나 기억할 부분

주기가 긴 12 → 3 → 2 순서로 조건을 배치하면 겹치는 날짜의 우선순위가 코드에 그대로 드러납니다. 기존 홀수 분기 안의 i % 12 == 0은 성립할 수 없어 제거할 수 있습니다. 성능 차이보다 중첩을 줄이는 개선입니다.

## 개선 예시 코드

설명한 개선을 적용한 완전한 C++ 실행 코드입니다. 원래 제출 소스는 변경하지 않습니다.

```cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;
    int classroom = 0, hallway = 0, restroom = 0;
    for (int day = 1; day <= n; ++day) {
        if (day % 12 == 0) ++restroom;
        else if (day % 3 == 0) ++hallway;
        else if (day % 2 == 0) ++classroom;
    }
    cout << classroom << ' ' << hallway << ' ' << restroom;
    return 0;
}
```

## 작은 값으로 따라가기

6일은 3의 배수이므로 복도, 12일은 화장실만 셉니다. 1~12일은 교실 4회, 복도 3회, 화장실 1회입니다.

## 복잡도

현재·예시 모두 시간 O(n), 추가 공간 O(1).

## 확인 범위

문서의 예시 코드를 로컬 C++17 환경에서 컴파일하고, 문제 예제와 별도 확인 입력을 합해 4건의 출력을 대조했습니다. 비교 시 줄 끝 공백과 마지막 줄바꿈만 무시했습니다. 위 값 변화 설명은 코드 흐름을 수작업으로 추적한 내용입니다. 실행 시간 벤치마크나 코드트리 재제출은 하지 않았습니다.
