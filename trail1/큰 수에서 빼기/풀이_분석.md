## 현재 풀이와 좋은 점

두 수 중 큰 쪽에서 작은 쪽을 빼 차이를 양수 또는 0으로 출력합니다.

## 다듬거나 기억할 부분

현재 비교 두 갈래는 절댓값의 의미를 직접 보여줍니다. abs를 쓸 수 있지만 기초 조건문 학습에서는 현 구조가 적절합니다.

## 복습 예시 코드

현재 풀이 구조를 유지한 완전한 C++ 실행 코드입니다. 원래 제출 소스는 변경하지 않습니다.

```cpp
#include <iostream>
using namespace std;

int main() {
    int A; int B;

    cin >> A >> B;

    if (A > B) {
        cout << A-B;
    } else {
        cout << B-A;
    }
    
    return 0;
}
```

## 작은 값으로 따라가기

8과 3도, 3과 8도 결과 5입니다. 같으면 0입니다.

## 복잡도

시간·추가 공간 O(1).

## 확인 범위

문서의 예시 코드를 로컬 C++17 환경에서 컴파일하고, 문제 예제와 별도 확인 입력을 합해 1건의 출력을 대조했습니다. 비교 시 줄 끝 공백과 마지막 줄바꿈만 무시했습니다. 위 값 변화 설명은 코드 흐름을 수작업으로 추적한 내용입니다. 실행 시간 벤치마크나 코드트리 재제출은 하지 않았습니다.
