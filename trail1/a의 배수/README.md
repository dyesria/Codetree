## 문제

두 정수 $N$, $a$가 순서대로 주어지면, `while`문을 사용해 $1$부터 $N$까지의 정수를 순서대로 확인하여 해당 수가 $a$의 배수이면 $1$을, 아니면 $0$을 한 줄에 하나씩 출력하는 프로그램을 작성하세요.

## 입력

첫 번째 줄에 정수 $N$과 정수 $a$가 공백으로 구분되어 주어진다.

## 제한 조건

- $1 \le N \le 100$
- $1 \le a \le 100$

## 출력

$N$개의 줄에 걸쳐 정답을 출력한다. 이 중 $i$번째 줄에는 $i$를 확인한 결과를 출력한다.

## 입력 예제

### 예제 1

입력

```text
3 2
```

출력

```text
0
1
0
```

### 예제 2

입력

```text
2 3
```

출력

```text
0
0
```

• Time Limit: 500 ms
