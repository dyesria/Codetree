## 문제

문자를 입력받아서 $8$회 출력하는 프로그램을 작성해보세요.

## 입력

첫 번째 줄에 문자를 입력받습니다.

## 출력

입력받은 문자를 사이에 공백없이 $8$회 출력합니다.

## 입력 예제

### 예제 1

입력

```text
G
```

출력

```text
GGGGGGGG
```

• Time Limit: 500 ms
