## 현재 풀이와 좋은 점

97과 13을 문자열로 표시하고 뺄셈을 계산해 출력합니다.

## 다듬거나 기억할 부분

원문의 변수 선언 연습을 드러내도록 a,b에 저장한 값을 표시와 계산에 함께 사용하면 좋습니다. 실행 시간 개선 목적은 아닙니다.

## 개선 예시 코드

설명한 개선을 적용한 완전한 C++ 실행 코드입니다. 원래 제출 소스는 변경하지 않습니다.

```cpp
#include <iostream>
using namespace std;

int main() {
    int a = 97, b = 13;
    cout << a << " - " << b << " = " << a - b;
    return 0;
}
```

## 작은 값으로 따라가기

a=97,b=13 → a-b=84 → 97 - 13 = 84입니다.

## 복잡도

시간·추가 공간 O(1).

## 확인 범위

문서의 예시 코드를 로컬 C++17 환경에서 컴파일하고, 문제 예제와 별도 확인 입력을 합해 1건의 출력을 대조했습니다. 비교 시 줄 끝 공백과 마지막 줄바꿈만 무시했습니다. 위 값 변화 설명은 코드 흐름을 수작업으로 추적한 내용입니다. 실행 시간 벤치마크나 코드트리 재제출은 하지 않았습니다.
