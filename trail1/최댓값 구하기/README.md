## 문제

$3$개의 정수 $a$, $b$, $c$를 입력받았을 때, 최댓값을 출력하는 프로그램을 작성해보세요.

## 입력

첫 번째 줄에 정수 $a$, $b$, $c$가 공백을 사이에 두고 주어집니다.

## 제한 조건

- $-100 \le a \le 100$
- $-100 \le b \le 100$
- $-100 \le c \le 100$

## 출력

$a$, $b$, $c$ 의 값들 중 가장 큰 값 하나를 출력합니다.

## 입력 예제

### 예제 1

입력

```text
1 3 5
```

출력

```text
5
```

### 예제 2

입력

```text
34 34 97
```

출력

```text
97
```

• Time Limit: 500 ms
