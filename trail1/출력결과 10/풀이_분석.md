## 핵심 원리

128보다 작은 양의 약수만 합산합니다. i<n이므로 128 자신은 제외됩니다.

## 순서대로 따라가기

약수는 1,2,4,8,16,32,64입니다. 누적합은 1 → 3 → 7 → 15 → 31 → 63 → 127입니다.

## 기억할 부분

원문은 변수 result의 값을 묻습니다. 아래 복습 코드는 그 값을 눈으로 볼 수 있도록 마지막 출력만 덧붙입니다.

## 복습 예시 코드

제시 코드를 C++에서 확인하기 위한 완전한 실행 예시입니다. 필요한 main·출력을 보충하거나 위 설명에 맞게 정리했습니다.

```cpp
#include <iostream>
using namespace std;

int main() {
    int n = 128, result = 0; 
    for (int i = 1; i < n; i++) {
        if (n % i == 0) { 
            result += i;
        } 
    }
    cout << result;
    return 0;
}
```

## 복잡도

고정 n=128에서는 O(1). 일반 n에서는 시간 O(n), 추가 공간 O(1).

## 확인 범위

문서의 예시 코드를 로컬 C++17 환경에서 컴파일하고, 복습 확인 입력 1건의 출력을 대조했습니다. 비교 시 줄 끝 공백과 마지막 줄바꿈만 무시했습니다. 위 값 변화 설명은 코드 흐름을 수작업으로 추적한 내용입니다. 실행 시간 벤치마크나 코드트리 재제출은 하지 않았습니다.
