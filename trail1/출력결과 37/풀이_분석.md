## 핵심 원리

3N+1 변환을 정확히 다섯 번 해서 처음 1에 도달하는 시작값을 찾습니다. 모든 정수를 임의 범위까지 대입하는 대신 1에서 역으로 추적할 수 있습니다.

## 순서대로 따라가기

1의 직전은 2, 그 직전은 4, 다음은 8, 다음은 16입니다. 다섯 단계 전은 32 또는 5입니다.

- 32 → 16 → 8 → 4 → 2 → 1
- 5 → 16 → 8 → 4 → 2 → 1

따라서 시작값의 개수는 2입니다.

## 기억할 부분

역연산 후보는 2x와 (x-1)/3입니다. 후자는 양의 홀수일 때만 허용합니다. 1은 이미 종료 상태이므로 중간에 다시 넣어 더 긴 경로를 세지 않습니다.

## 복습 예시 코드

제시 코드를 C++에서 확인하기 위한 완전한 실행 예시입니다. 필요한 main·출력을 보충하거나 위 설명에 맞게 정리했습니다.

```cpp
#include <iostream>
using namespace std;

int main() {
    int m = 0;
    int n;
    cin >> n;
    while (n != 1) {
        if(n % 2 == 0) n /= 2;
        else n = 3 * n + 1;
        m++;
    }
    cout << m;
    return 0;
}
```

## 복잡도

시작값 하나를 검사할 때 실제 변환 횟수 T에 대해 시간 O(T), 추가 공간 O(1).

## 확인 범위

문서의 예시 코드를 로컬 C++17 환경에서 컴파일하고, 복습 확인 입력 2건의 출력을 대조했습니다. 비교 시 줄 끝 공백과 마지막 줄바꿈만 무시했습니다. 위 값 변화 설명은 코드 흐름을 수작업으로 추적한 내용입니다. 실행 시간 벤치마크나 코드트리 재제출은 하지 않았습니다.
