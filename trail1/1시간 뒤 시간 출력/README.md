## 문제

$h$:$m$ 모양의 시간과 분으로 이루어져 있는 시간을 입력받아 $1$시간 뒤의 시간을 출력하는 프로그램을 작성해보세요.

## 입력

첫 번째 줄에 현재 시간이 $h$:$m$ 형태로 주어집니다. $h$는 시간을, $m$은 분을 나타냅니다.

## 제한 조건

- $1 \le h \le 22$
- $0 \le m \lt 60$

## 출력

입력받은 시간으로부터 $1$시간 뒤의 시간을 입력과 동일한 형태 $h$:$m$에 맞춰 출력합니다.

## 입력 예제

### 예제 1

입력

```text
1:59
```

출력

```text
2:59
```

### 예제 2

입력

```text
22:1
```

출력

```text
23:1
```

## 제한

• Time Limit: 500 ms

• Memory Limit: 64 MiB
