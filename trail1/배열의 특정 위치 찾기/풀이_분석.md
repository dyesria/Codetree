## 현재 풀이와 좋은 점

10개 값을 배열에 저장하고, 짝수 번째 합과 3의 배수 번째 평균을 두 번 순회해 구합니다. 0부터 시작하는 인덱스를 조건에 맞춰 사용했습니다.

## 다듬거나 기억할 부분

사람이 세는 위치 position을 i+1로 이름 붙이면 cnt와 divide의 역할이 명확해집니다. 배열 학습 목적을 유지한 채 한 번의 입력 반복에서 두 집계를 같이 할 수 있습니다. 두 조건은 겹칠 수 있어 독립된 if여야 합니다.

## 개선 예시 코드

설명한 개선을 적용한 완전한 Java 실행 코드입니다. 원래 제출 소스는 변경하지 않습니다.

```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        int[] values = new int[10];
        int evenSum = 0, thirdSum = 0, thirdCount = 0;
        for (int i = 0; i < values.length; ++i) {
            values[i] = scanner.nextInt();
            int position = i + 1;
            if (position % 2 == 0) evenSum += values[i];
            if (position % 3 == 0) {
                thirdSum += values[i];
                ++thirdCount;
            }
        }
        System.out.printf("%d %.1f", evenSum, (double) thirdSum / thirdCount);
    }
}
```

## 작은 값으로 따라가기

1~10을 차례로 넣으면 짝수 번째 합 2+4+6+8+10=30, 3·6·9번째 평균 (3+6+9)/3=6.0입니다.

## 복잡도

현재 2회 순회와 예시 1회 순회 모두 K개로 일반화하면 O(K). 고정 배열 10칸은 추가 공간 O(1).

## 확인 범위

문서의 예시 코드를 로컬 Java 21 환경에서 컴파일하고, 문제 예제와 별도 확인 입력을 합해 2건의 출력을 대조했습니다. 비교 시 줄 끝 공백과 마지막 줄바꿈만 무시했습니다. 위 값 변화 설명은 코드 흐름을 수작업으로 추적한 내용입니다. 실행 시간 벤치마크나 코드트리 재제출은 하지 않았습니다.
