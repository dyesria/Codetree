## 현재 풀이와 좋은 점

N을 2로 나눌 때마다 count를 증가시켜 지수를 셉니다. 로그 함수 없이 정수 연산으로 답을 얻습니다.

## 다듬거나 기억할 부분

N이 2의 거듭제곱이라는 조건 덕분에 N > 1인 동안 항상 짝수입니다. 안쪽 짝수 검사를 없애면 매 반복마다 값이 감소한다는 사실이 분명해집니다. 임의의 양의 정수까지 지원하려는 예시는 아닙니다.

## 개선 예시 코드

설명한 개선을 적용한 완전한 Java 실행 코드입니다. 원래 제출 소스는 변경하지 않습니다.

```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        int n = scanner.nextInt();
        int count = 0;
        while (n > 1) {
            n /= 2;
            ++count;
        }
        System.out.print(count);
    }
}
```

## 작은 값으로 따라가기

8 → 4 → 2 → 1로 3번 나눕니다. 최대 입력 1024는 10번입니다.

## 복잡도

시간 O(log N), 추가 공간 O(1).

## 확인 범위

문서의 예시 코드를 로컬 Java 21 환경에서 컴파일하고, 문제 예제와 별도 확인 입력을 합해 3건의 출력을 대조했습니다. 비교 시 줄 끝 공백과 마지막 줄바꿈만 무시했습니다. 위 값 변화 설명은 코드 흐름을 수작업으로 추적한 내용입니다. 실행 시간 벤치마크나 코드트리 재제출은 하지 않았습니다.
