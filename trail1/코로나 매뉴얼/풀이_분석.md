## 현재 풀이와 좋은 점

세 사람 각각의 조건을 확인해 emergencyCount를 올리고, 2명 이상이면 E를 출력합니다. 개수로 결론을 내리는 방식이 명확합니다.

## 다듬거나 기억할 부분

사람마다 같은 중첩 if와 변수를 반복하는 대신 3회 입력 반복으로 합칠 수 있습니다. 증상과 체온은 AND로 묶어 한 사람의 조건을 표현합니다. 이 문서는 문제에서 정한 분류 규칙만 설명합니다.

## 개선 예시 코드

설명한 개선을 적용한 완전한 C++ 실행 코드입니다. 원래 제출 소스는 변경하지 않습니다.

```cpp
#include <iostream>
using namespace std;

int main() {
    int emergencyCount = 0;
    for (int i = 0; i < 3; ++i) {
        char symptom;
        int temperature;
        cin >> symptom >> temperature;
        if (symptom == 'Y' && temperature >= 37) ++emergencyCount;
    }
    cout << (emergencyCount >= 2 ? 'E' : 'N');
    return 0;
}
```

## 작은 값으로 따라가기

Y 37, N 40, Y 38이면 집계가 1 → 1 → 2가 되어 E를 출력합니다. N 40은 두 조건을 모두 만족하지 않습니다.

## 복잡도

고정 세 명이므로 시간·추가 공간 O(1). K명이라면 시간 O(K).

## 확인 범위

문서의 예시 코드를 로컬 C++17 환경에서 컴파일하고, 문제 예제와 별도 확인 입력을 합해 2건의 출력을 대조했습니다. 비교 시 줄 끝 공백과 마지막 줄바꿈만 무시했습니다. 위 값 변화 설명은 코드 흐름을 수작업으로 추적한 내용입니다. 실행 시간 벤치마크나 코드트리 재제출은 하지 않았습니다.
