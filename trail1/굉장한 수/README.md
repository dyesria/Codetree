## 문제

자연수 $N$을 입력받아 $N$이 굉장한 수인지 판단하는 프로그램을 작성해보세요.

굉장한 수이기 위해서는 다음 두 조건 중 하나를 만족해야 합니다.

- 홀수이면서 $3$의 배수인 수
- 짝수이면서 $5$의 배수인 수

## 입력

첫 번째 줄에는 $N$이 주어집니다.

## 제한 조건

- $1 \leq N \leq 100$

## 출력

입력받은 수가 굉장한 수라면 `true`를 아니라면 `false`를 출력합니다.

## 입력 예제

### 예제 1

입력

```text
9
```

출력

```text
true
```

### 예제 2

입력

```text
18
```

출력

```text
false
```

• Time Limit: 500 ms
