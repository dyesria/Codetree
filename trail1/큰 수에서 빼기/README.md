## 문제

두 개의 정수를 입력받아 큰 수에서 작은 수를 뺀 차를 출력하는 프로그램을 작성해주세요.

## 입력

첫 번째 줄에 정수 $A, B$가 공백을 사이에 두고 주어집니다.

## 제한 조건

- $1 \le A, B \le 100$

## 출력

큰 수에서 작은 수를 뺀 값을 출력합니다.

## 입력 예제

### 예제 1

입력

```text
31 64
```

출력

```text
33
```

• Time Limit: 500 ms

• Memory Limit: 64 MiB
