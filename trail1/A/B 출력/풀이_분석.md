## 현재 풀이와 좋은 점

정수 몫을 출력한 뒤 나머지에 10을 곱해 소수 한 자리씩 20번 구합니다. 부동소수점 오차 없이 필요한 자리를 만드는 접근이 좋습니다.

## 다듬거나 기억할 부분

나머지 변수도 long long으로 맞추면 A,B와 자료형이 일관됩니다. 현재 제한을 넘는 큰 수로 확장할 때 remainder*10의 범위도 점검해야 합니다. 이 방법은 21번째 자리로 반올림하지 않고 20자리까지 구하는 방식입니다.

## 개선 예시 코드

설명한 개선을 적용한 완전한 C++ 실행 코드입니다. 원래 제출 소스는 변경하지 않습니다.

```cpp
#include <iostream>
using namespace std;

int main() {
    long long a, b;
    cin >> a >> b;
    cout << a / b << '.';
    long long remainder = a % b;
    for (int digit = 0; digit < 20; ++digit) {
        remainder *= 10;
        cout << remainder / b;
        remainder %= b;
    }
    return 0;
}
```

## 작은 값으로 따라가기

1/8: 나머지 1 → 10/8에서 1, 나머지 2 → 20/8에서 2, 나머지 4 → 40/8에서 5, 이후 0을 계속 출력합니다.

## 복잡도

20자리 고정이라 시간·추가 공간 O(1). D자리로 일반화하면 시간 O(D).

## 확인 범위

문서의 예시 코드를 로컬 C++17 환경에서 컴파일하고, 문제 예제와 별도 확인 입력을 합해 3건의 출력을 대조했습니다. 비교 시 줄 끝 공백과 마지막 줄바꿈만 무시했습니다. 위 값 변화 설명은 코드 흐름을 수작업으로 추적한 내용입니다. 실행 시간 벤치마크나 코드트리 재제출은 하지 않았습니다.
