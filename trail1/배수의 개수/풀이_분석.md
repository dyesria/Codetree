## 현재 풀이와 좋은 점

3의 배수와 5의 배수를 별개의 if로 확인합니다. 15, 30, 60처럼 두 조건을 모두 만족하는 수를 양쪽에 포함하는 구현이 좋습니다.

## 다듬거나 기억할 부분

여기의 두 if를 else if로 합치면 두 집계가 동시에 증가하지 못합니다. 지금처럼 독립 조건을 유지하는 것이 가장 중요한 설계입니다.

## 복습 예시 코드

현재 풀이 구조를 유지한 완전한 C++ 실행 코드입니다. 원래 제출 소스는 변경하지 않습니다.

```cpp
#include <iostream>
using namespace std;

int main() {
    int N;
    int multipleOf3 = 0;
    int multipleOf5 = 0;
    
    for (int i=1; i<=10; i++) {
        cin >> N;

        if (N % 3 == 0) {
            multipleOf3++;
        } 
        if (N % 5 == 0) {
            multipleOf5++;
        }
    }

    cout << multipleOf3 << " " << multipleOf5;
    return 0;
}
```

## 작은 값으로 따라가기

30 하나를 읽으면 multipleOf3과 multipleOf5가 모두 1 증가합니다. 7은 어느 집계도 바꾸지 않습니다.

## 복잡도

고정 10개이므로 시간·추가 공간 O(1). K개라면 시간 O(K).

## 확인 범위

문서의 예시 코드를 로컬 C++17 환경에서 컴파일하고, 문제 예제와 별도 확인 입력을 합해 1건의 출력을 대조했습니다. 비교 시 줄 끝 공백과 마지막 줄바꿈만 무시했습니다. 위 값 변화 설명은 코드 흐름을 수작업으로 추적한 내용입니다. 실행 시간 벤치마크나 코드트리 재제출은 하지 않았습니다.
