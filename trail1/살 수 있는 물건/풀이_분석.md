## 현재 풀이와 좋은 점

1000원 이상인지 먼저 보고 3000원 이상이면 book을 출력 후 종료합니다.

## 다듬거나 기억할 부분

비싼 기준부터 평평하게 나열하면 중첩과 중간 return을 줄일 수 있습니다. 결과는 동일하고 가독성이 개선됩니다.

## 개선 예시 코드

설명한 개선을 적용한 완전한 C++ 실행 코드입니다. 원래 제출 소스는 변경하지 않습니다.

```cpp
#include <iostream>
using namespace std;

int main() {
    int money;
    cin >> money;
    if (money >= 3000) cout << "book";
    else if (money >= 1000) cout << "mask";
    else cout << "no";
    return 0;
}
```

## 작은 값으로 따라가기

3000→book, 2999→mask, 999→no입니다.

## 복잡도

시간·추가 공간 O(1).

## 확인 범위

문서의 예시 코드를 로컬 C++17 환경에서 컴파일하고, 문제 예제와 별도 확인 입력을 합해 3건의 출력을 대조했습니다. 비교 시 줄 끝 공백과 마지막 줄바꿈만 무시했습니다. 위 값 변화 설명은 코드 흐름을 수작업으로 추적한 내용입니다. 실행 시간 벤치마크나 코드트리 재제출은 하지 않았습니다.
