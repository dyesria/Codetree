## 핵심 원리

i는 1에서 시작하고 짝수일 때만 증가하므로 계속 1입니다. tmp가 실제 종료를 결정합니다.

## 순서대로 따라가기

tmp는 0 → 1 → 2 → 3 → 4 → 5 → 6으로 바뀝니다. 다음 반복에서 tmp>5가 참이라 더하지 않고 멈춰 출력은 6입니다.

## 기억할 부분

while(i<10)만 보고 i가 10까지 간다고 생각하면 안 됩니다. 각 변수의 갱신 조건과 break 검사 위치를 함께 추적하세요.

## 복습 예시 코드

제시 코드를 C++에서 확인하기 위한 완전한 실행 예시입니다. 필요한 main·출력을 보충하거나 위 설명에 맞게 정리했습니다.

```cpp
#include <iostream>
using namespace std;

int main() {
    int tmp = 0, i = 1;
    while(i < 10) {  
        if(i % 2 == 0)     
            i++;         
        if(tmp > 5)    
            break;   
        tmp += i; 
    }
    cout << tmp << endl;
    return 0;
}
```

## 복잡도

주어진 상수에서는 시간·공간 O(1).

## 확인 범위

문서의 예시 코드를 로컬 C++17 환경에서 컴파일하고, 복습 확인 입력 1건의 출력을 대조했습니다. 비교 시 줄 끝 공백과 마지막 줄바꿈만 무시했습니다. 위 값 변화 설명은 코드 흐름을 수작업으로 추적한 내용입니다. 실행 시간 벤치마크나 코드트리 재제출은 하지 않았습니다.
