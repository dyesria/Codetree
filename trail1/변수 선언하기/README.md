## 문제

변수 $a$, $b$에 각각 정수 $3$과 대문자 `C`을 넣어주고, 차례로 출력하는 프로그램을 작성해보세요.

## 입력

입력이 주어지지 않습니다.

## 출력

첫 번째 줄에는 $a$를 출력합니다. 두 번째 줄에는 $b$를 출력합니다.

## 입력 예제

### 예제 1

출력

```text
3
C
```
