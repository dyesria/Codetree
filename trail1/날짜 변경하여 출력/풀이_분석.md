## 현재 풀이와 좋은 점

년·월·일 사이의 점을 char로 받아 처리하고 월-일-년 순서로 출력합니다.

## 다듬거나 기억할 부분

구분자를 dot으로 이름 붙여 읽는 대상이 명확합니다. 입력 형식이 고정된 이 문제에서는 복잡한 날짜 라이브러리가 필요하지 않습니다.

## 복습 예시 코드

현재 풀이 구조를 유지한 완전한 C++ 실행 코드입니다. 원래 제출 소스는 변경하지 않습니다.

```cpp
#include <iostream>
using namespace std;

int main() {
    int yyyy; int mm; int dd;
    char dot;
    cin >> yyyy >> dot >> mm >> dot >> dd;

    cout << mm << "-" << dd << "-" << yyyy;
    return 0;
}
```

## 작은 값으로 따라가기

2025.12.25 → yyyy=2025,mm=12,dd=25 → 12-25-2025입니다.

## 복잡도

시간·추가 공간 O(1).

## 확인 범위

문서의 예시 코드를 로컬 C++17 환경에서 컴파일하고, 문제 예제와 별도 확인 입력을 합해 2건의 출력을 대조했습니다. 비교 시 줄 끝 공백과 마지막 줄바꿈만 무시했습니다. 위 값 변화 설명은 코드 흐름을 수작업으로 추적한 내용입니다. 실행 시간 벤치마크나 코드트리 재제출은 하지 않았습니다.
