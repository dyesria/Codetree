## 문제

양쪽눈의 시력을 실수(real number)로 입력받아 모두 $1.0$ 이상이면 $High$, 모두 $0.5$ 이상이면 $Middle$, 아니면 $Low$라고 출력하는 프로그램을 작성해주세요.

## 입력

한 줄에 하나씩 두 실수 $a$, $b$가 주어집니다.

## 제한 조건

- $0 \le a, b \le 5$

## 출력

출력값에 해당하는 문자열을 출력합니다.

## 입력 예제

### 예제 1

입력

```text
1.3
1.0
```

출력

```text
High
```

### 예제 2

입력

```text
0.8
0.4
```

출력

```text
Low
```
