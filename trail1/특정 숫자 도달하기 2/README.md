## 문제

정수 $N$의 값을 입력받아 $1$까지 차례로 출력하는 프로그램을 작성해보세요.

## 입력

첫 번째 줄에 정수 $N$이 주어집니다.

## 제한 조건

- $1 \le N \le 100$

## 출력

입력받은 정수 $N$부터 $1$까지 공백을 사이에 두고 출력합니다.

## 입력 예제

### 예제 1

입력

```text
8
```

출력

```text
8 7 6 5 4 3 2 1
```

• Time Limit: 500 ms
