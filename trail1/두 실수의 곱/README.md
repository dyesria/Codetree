## 문제

변수 `a`, `b`에 각각 $5.26$, $8.27$을 넣어주고, 두 수의 곱을 소수점 셋째 자리까지만 출력하는 프로그램을 작성하세요.

## 입력

입력형식이 주어지지 않습니다.

## 출력

첫 번째 줄에 결과값을 소수점 셋째 자리까지만 출력합니다.

## 입력 예제

### 예제 1

출력

```text
43.500
```

예제 설명

예제 1번에서, $5.26 \times 8.27 = 43.5002$ 이므로 셋째자리까지 반올림하여 출력합니다.
