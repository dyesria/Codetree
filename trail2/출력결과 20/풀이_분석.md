## 핵심 원리

함수 호출마다 다음 행을 왼쪽으로 한 칸 회전한 값을 현재 행에 덮어씁니다. 다음 호출은 갱신된 배열을 읽습니다.

## 순서대로 따라가기

| 호출 | 바뀌는 행 | 변경 후 값 |
|---|---|---|
| f(1) | 행 1 | 4,0,0,1 |
| f(2) | 행 2 | 0,1,5,2 |
| f(0) | 행 0 | 0,0,1,4 |

마지막 합은 a[0][1]+a[1][2]+a[2][3]=0+0+2=2입니다.

## 기억할 부분

모든 호출이 원래 배열을 읽는다고 생각하면 안 됩니다. 호출 한 번이 끝날 때마다 바뀐 행을 기록하세요.

## 복습 예시 코드

제시 코드를 C++에서 확인하기 위한 완전한 실행 예시입니다. 필요한 main·출력을 보충하거나 위 설명에 맞게 정리했습니다.

```cpp
#include <iostream>
using namespace std;

int a[3][4] = {
    {2, 0, 1, 5},
    {0, 4, 1, 1},
    {1, 4, 0, 0}
};
void f(int b) {
    int i;
    for(i = 0; i < 4; i++) {
        a[b][i] = a[(b + 1) % 3][(i + 1) % 4];
    }
}
int main() {
    int i, tot = 0;
    f(1);
    f(2);
    f(0);
    for(i = 0; i < 3; i++) {
        tot = tot + a[i][(i + 1) % 4];
    }
    cout << tot;
    return 0;
}
```

## 복잡도

3×4 배열과 호출 수가 고정이므로 시간·공간 O(1).

## 확인 범위

문서의 예시 코드를 로컬 C++17 환경에서 컴파일하고, 복습 확인 입력 1건의 출력을 대조했습니다. 비교 시 줄 끝 공백과 마지막 줄바꿈만 무시했습니다. 위 값 변화 설명은 코드 흐름을 수작업으로 추적한 내용입니다. 실행 시간 벤치마크나 코드트리 재제출은 하지 않았습니다.
