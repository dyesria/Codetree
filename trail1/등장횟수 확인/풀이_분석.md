## 현재 풀이와 좋은 점

다섯 수를 읽고 짝수일 때만 evenCnt를 1 늘립니다. 입력 전체를 저장하지 않고 즉시 집계하며, 변수 이름에도 세는 대상이 드러납니다.

## 다듬거나 기억할 부분

이미 간결한 풀이입니다. evenCnt는 수의 합이 아니라 조건을 만족한 횟수이므로 += n이 아닌 ++를 유지하는 것이 핵심입니다.

## 복습 예시 코드

현재 풀이 구조를 유지한 완전한 C++ 실행 코드입니다. 원래 제출 소스는 변경하지 않습니다.

```cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    int evenCnt = 0;

    for (int i=1; i<=5; i++) {
        cin >> n;

        if (n % 2 == 0) {
            evenCnt++;
        }
    }

    cout << evenCnt;
    return 0;
}
```

## 작은 값으로 따라가기

124, 341, 547, 56, 23을 읽으면 evenCnt는 1, 1, 1, 2, 2가 됩니다.

## 복잡도

고정 5개이므로 시간·추가 공간 O(1). 입력 개수를 K로 일반화하면 시간 O(K).

## 확인 범위

문서의 예시 코드를 로컬 C++17 환경에서 컴파일하고, 문제 예제와 별도 확인 입력을 합해 1건의 출력을 대조했습니다. 비교 시 줄 끝 공백과 마지막 줄바꿈만 무시했습니다. 위 값 변화 설명은 코드 흐름을 수작업으로 추적한 내용입니다. 실행 시간 벤치마크나 코드트리 재제출은 하지 않았습니다.
