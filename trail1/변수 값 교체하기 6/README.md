## 문제

정수 $a$에 값 $2$을 넣고, 정수 $b$에 값 $5$를 넣은 뒤, 두 값을 교환하여 $a$, $b$를 순서대로 출력하는 프로그램을 작성해보세요.

## 입력

입력이 주어지지 않습니다.

## 출력

첫 번째 줄에는 정수 $a$를 출력합니다. 두 번째 줄에는 정수 $b$를 출력합니다.

## 입력 예제

### 예제 1

출력

```text
5
2
```
