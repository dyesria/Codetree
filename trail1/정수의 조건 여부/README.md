## 문제

정수 $a$를 입력받았을 때, $a$가 $113$ 이상일 경우엔 $1$을 출력하고, 그 외의 경우엔 $0$을 출력하는 프로그램을 작성해보세요.

## 입력

첫 번째 줄에 정수 $a$가 주어집니다.

## 제한 조건

- $-1000 \le a \le 1000$

## 출력

첫 번째 줄에는 $a$에 따른 경우의 값을 출력합니다.

## 입력 예제

### 예제 1

입력

```text
200
```

출력

```text
1
```

### 예제 2

입력

```text
-113
```

출력

```text
0
```
