## 문제

물의 온도를 정수로 입력받아 $0$℃ 미만일경우엔 `ice`, $100$℃ 이상일때는`vapor`, 그 외의 경우는 `water` 라고 출력하는 프로그램을 작성해주세요.

## 입력

첫 번째 줄에는 물의 온도인 정수 $n$이 주어집니다.

## 제한 조건

- $-200 \le n \le 200$

## 출력

물의 온도에 따른 현재 상태를 문자열로 출력해주세요.

## 입력 예제

### 예제 1

입력

```text
-13
```

출력

```text
ice
```

### 예제 2

입력

```text
98
```

출력

```text
water
```
