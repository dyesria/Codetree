## 현재 풀이와 좋은 점

두 실수를 곱하고 소수 셋째 자리까지 표시합니다.

## 다듬거나 기억할 부분

현재 계산·출력 순서가 간결합니다. fixed를 함께 지정해야 precision(3)이 소수 이하 세 자리를 뜻합니다.

## 복습 예시 코드

현재 풀이 구조를 유지한 완전한 C++ 실행 코드입니다. 원래 제출 소스는 변경하지 않습니다.

```cpp
#include <iostream>
#include <iomanip>
using namespace std;

int main() {
    double a = 5.26;
    double b = 8.27;

    cout << fixed;
    cout.precision(3);

    cout << a * b;

    return 0;
}
```

## 작은 값으로 따라가기

5.26×8.27=43.5002이며 출력 형식에 따라 43.500이 됩니다.

## 복잡도

시간·추가 공간 O(1).

## 확인 범위

문서의 예시 코드를 로컬 C++17 환경에서 컴파일하고, 문제 예제와 별도 확인 입력을 합해 1건의 출력을 대조했습니다. 비교 시 줄 끝 공백과 마지막 줄바꿈만 무시했습니다. 위 값 변화 설명은 코드 흐름을 수작업으로 추적한 내용입니다. 실행 시간 벤치마크나 코드트리 재제출은 하지 않았습니다.
