## 현재 풀이와 좋은 점

1부터 큰 수 직전까지 나누어 보며 마지막 공약수를 기억합니다. 두 수가 같을 때는 따로 처리합니다.

## 다듬거나 기억할 부분

공약수는 작은 수보다 클 수 없으므로 학습용 탐색은 1~min(n,m)면 충분합니다. 답을 1로 초기화하면 초기 상태도 명확합니다. 아래 유클리드 대안은 gcd(a,b)=gcd(b,a%b)를 사용하며 값을 받아 출력하는 함수 요구를 유지합니다.

## 개선 예시 코드

설명한 개선을 적용한 완전한 C++ 실행 코드입니다. 원래 제출 소스는 변경하지 않습니다.

```cpp
#include <iostream>
using namespace std;

void printGcd(int a, int b) {
    while (b != 0) {
        int remainder = a % b;
        a = b;
        b = remainder;
    }
    cout << a;
}

int main() {
    int n, m;
    cin >> n >> m;
    printGcd(n, m);
    return 0;
}
```

## 작은 값으로 따라가기

12,18 → 18,12 → 12,6 → 6,0. 나머지가 0이면 남은 6이 최대공약수입니다.

## 복잡도

현재는 두 수가 다를 때 O(max(n,m)); 작은 수까지 탐색하면 O(min(n,m)); 유클리드 예시는 O(log(min(n,m)+1)). 추가 공간은 모두 O(1).

## 확인 범위

문서의 예시 코드를 로컬 C++17 환경에서 컴파일하고, 문제 예제와 별도 확인 입력을 합해 4건의 출력을 대조했습니다. 비교 시 줄 끝 공백과 마지막 줄바꿈만 무시했습니다. 위 값 변화 설명은 코드 흐름을 수작업으로 추적한 내용입니다. 실행 시간 벤치마크나 코드트리 재제출은 하지 않았습니다.
