## 문제

$3$개의 정수를 입력받아 조건연산자를 이용하여 입력받은 수 중 최솟값을 출력하는 프로그램을 작성해주세요.

## 입력

첫 번째 줄에 정수 $a$, $b$, $c$가 공백을 사이에 두고 주어집니다.

## 제한 조건

- $-100 \le a, b, c \le 100$

## 출력

입력받은 $3$개의 정수 중 최솟값을 출력합니다.

## 입력 예제

### 예제 1

입력

```text
8 -5 10
```

출력

```text
-5
```
