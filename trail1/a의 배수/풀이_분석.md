## 현재 풀이와 좋은 점

1부터 N까지 각 수가 a의 배수인지 확인하고 1 또는 0을 줄마다 출력합니다.

## 다듬거나 기억할 부분

n != N+1보다 n <= N이 범위를 바로 보여줍니다. C++에서 bool은 기본 출력 형식으로 0/1이므로 같은 문자열 출력 분기를 합칠 수 있습니다.

## 개선 예시 코드

설명한 개선을 적용한 완전한 C++ 실행 코드입니다. 원래 제출 소스는 변경하지 않습니다.

```cpp
#include <iostream>
using namespace std;

int main() {
    int n, divisor;
    cin >> n >> divisor;
    int value = 1;
    while (value <= n) {
        cout << (value % divisor == 0) << '\n';
        ++value;
    }
    return 0;
}
```

## 작은 값으로 따라가기

N=4,a=2이면 나머지는 1,0,1,0이고 출력은 0,1,0,1입니다.

## 복잡도

시간 O(N), 추가 공간 O(1).

## 확인 범위

문서의 예시 코드를 로컬 C++17 환경에서 컴파일하고, 문제 예제와 별도 확인 입력을 합해 2건의 출력을 대조했습니다. 비교 시 줄 끝 공백과 마지막 줄바꿈만 무시했습니다. 위 값 변화 설명은 코드 흐름을 수작업으로 추적한 내용입니다. 실행 시간 벤치마크나 코드트리 재제출은 하지 않았습니다.
