## 핵심 원리

테두리 외에 두 대각선을 별로 채워야 합니다. 주대각선은 row==col, 반대 대각선은 col==n-row+1입니다.

## 순서대로 따라가기

n=5에서 두 번째 행은 열 1·2·4·5에 별이 있어 ** **가 됩니다. 중앙 행의 별은 열 1·3·5에 놓입니다.

## 기억할 부분

C++에서는 보기의 or를 ||로 써도 같습니다. 아래 예시는 조건 이름을 나누어 테두리와 대각선을 읽기 쉽게 표현했습니다.

## 복습 예시 코드

제시 코드를 C++에서 확인하기 위한 완전한 실행 예시입니다. 필요한 main·출력을 보충하거나 위 설명에 맞게 정리했습니다.

```cpp
#include <iostream>
using namespace std;

void draw(int n) {
    for (int row = 1; row <= n; ++row) {
        for (int col = 1; col <= n; ++col) {
            bool border = row == 1 || row == n || col == 1 || col == n;
            bool diagonal = row == col || col == n - row + 1;
            cout << (border || diagonal ? '*' : ' ');
        }
        cout << '\n';
    }
}

int main() {
    draw(5);
    return 0;
}
```

## 복잡도

시간 O(n²), 추가 공간 O(1). 출력해야 하는 칸 수가 n²입니다.

## 확인 범위

문서의 예시 코드를 로컬 C++17 환경에서 컴파일하고, 복습 확인 입력 1건의 출력을 대조했습니다. 비교 시 줄 끝 공백과 마지막 줄바꿈만 무시했습니다. 위 값 변화 설명은 코드 흐름을 수작업으로 추적한 내용입니다. 실행 시간 벤치마크나 코드트리 재제출은 하지 않았습니다.
