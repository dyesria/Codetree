## 문제

정수 $a$를 입력받아 $a$가 $10$보다 작거나 $20$보다 큰 수인지를 판단하는 프로그램을 작성해보세요.

## 입력

첫 번째 줄에 $a$가 주어집니다.

## 제한 조건

- $1 \le a \le 100$

## 출력

첫 번째 줄에 $a$에 대한 정보를 출력합니다. $a$가 $10$보다 작거나 $20$보다 크다면 `yes`를, 아니라면 `no`를 출력합니다.

## 입력 예제

### 예제 1

입력

```text
10
```

출력

```text
no
```

### 예제 2

입력

```text
26
```

출력

```text
yes
```

• Time Limit: 500 ms
