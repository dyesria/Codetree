## 문제

정수 $N$이 주어지면, $N$개의 줄에 걸쳐 `12345^&*()_`를 출력하는 프로그램을 작성해보세요. 단, 몇 줄을 출력할지에 대한 인자값을 하나 받는 함수를 작성하여 문제를 해결해보세요.

## 입력

첫 번째 줄에 정수 $N$이 주어집니다.

## 제한 조건

- $1 \le N \le 100$

## 출력

첫 번째 줄부터 각 줄마다 문자열을 총 $N$번 출력합니다.

## 입력 예제

### 예제 1

입력

```text
4
```

출력

```text
12345^&*()_
12345^&*()_
12345^&*()_
12345^&*()_
```

## 제한

• Time Limit: 500 ms

• Memory Limit: 64 MiB
