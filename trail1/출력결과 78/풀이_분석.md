## 핵심 원리

첫 반복은 b를 a로 옮기듯 변화시키고 두 번째 반복은 a를 b로 옮깁니다. a+b는 계속 4입니다.

## 순서대로 따라가기

(2,2) → (3,1) → (4,0), 이어 (3,1) → (2,2) → (1,3) → (0,4). 출력은 4입니다.

## 기억할 부분

두 반복문은 순서대로 실행되며, 두 번째 반복은 첫 번째의 최종 상태에서 시작합니다.

## 복습 예시 코드

제시 코드를 C++에서 확인하기 위한 완전한 실행 예시입니다. 필요한 main·출력을 보충하거나 위 설명에 맞게 정리했습니다.

```cpp
#include <iostream>
using namespace std;

int main() {
    int a = 2;
    int b = 2;
    while(b > 0) {
        a++;    
        b--;     
    }
    while(a > 0) {    
        a--;    
        b++;
    }
    cout << b << endl;
    return 0;
}
```

## 복잡도

고정 입력에서는 O(1). 양의 초기값 A,B로 일반화하면 시간 O(A+B), 추가 공간 O(1).

## 확인 범위

문서의 예시 코드를 로컬 C++17 환경에서 컴파일하고, 복습 확인 입력 1건의 출력을 대조했습니다. 비교 시 줄 끝 공백과 마지막 줄바꿈만 무시했습니다. 위 값 변화 설명은 코드 흐름을 수작업으로 추적한 내용입니다. 실행 시간 벤치마크나 코드트리 재제출은 하지 않았습니다.
