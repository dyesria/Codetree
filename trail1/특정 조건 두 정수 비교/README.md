## 문제

두 정수 $A$, $B$를 입력받아 다음 두 값을 공백으로 구분해 한 줄에 출력하는 프로그램을 작성하세요.

- 첫 번째 값: $A$가 $B$보다 작으면 $1$, 아니면 $0$
- 두 번째 값: $A$와 $B$가 같으면 $1$, 아니면 $0$

## 입력

첫 번째 줄에 정수 $A$, $B$가 공백을 사이에 두고 주어집니다.

## 제한 조건

- $1 \le A, B \le 100$

## 출력

다음 두 값을 공백으로 구분해 한 줄에 출력합니다.

1. $A$가 $B$보다 작은지의 결과
2. $A$와 $B$가 같은지의 결과

## 입력 예제

### 예제 1

입력

```text
8 10
```

출력

```text
1 0
```

### 예제 2

입력

```text
15 15
```

출력

```text
0 1
```

## 힌트

Python에서는 print 함수 사용시 기본적으로 한 줄이 띄어지게 됩니다. 출력 후 뒤에 엔터가 아닌 공백을 출력하고 싶다면 `print(값, end=" ")` 형태로 작성해야 합니다.
