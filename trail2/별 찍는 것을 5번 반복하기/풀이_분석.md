## 현재 풀이와 좋은 점

별 10개를 출력하는 함수를 만들고 5번 호출합니다. 한 줄의 작업과 반복 횟수를 나눈 구조가 좋습니다.

## 다듬거나 기억할 부분

현재 풀이가 함수 연습 목적에 잘 맞습니다. 별 50개를 한꺼번에 출력하면 5행이라는 구조가 사라지므로 줄바꿈 위치를 유지하세요.

## 복습 예시 코드

현재 풀이 구조를 유지한 완전한 C++ 실행 코드입니다. 원래 제출 소스는 변경하지 않습니다.

```cpp
#include <iostream>
using namespace std;

void Print10Stars() {
    cout << "**********" << endl;
}

int main() {
    for(int i=1; i<=5; i++) {
        Print10Stars();
    }
    return 0;
}
```

## 작은 값으로 따라가기

함수 한 번은 별 10개+줄바꿈, 호출 5번은 5행 10열입니다.

## 복잡도

반복 수가 고정되어 시간·추가 공간 O(1).

## 확인 범위

문서의 예시 코드를 로컬 C++17 환경에서 컴파일하고, 문제 예제와 별도 확인 입력을 합해 1건의 출력을 대조했습니다. 비교 시 줄 끝 공백과 마지막 줄바꿈만 무시했습니다. 위 값 변화 설명은 코드 흐름을 수작업으로 추적한 내용입니다. 실행 시간 벤치마크나 코드트리 재제출은 하지 않았습니다.
