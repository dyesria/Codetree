## 현재 풀이와 좋은 점

입력 문자열을 정수로 변환하고 1~num을 출력합니다. 마지막 공백을 함수 두 개로 구분했습니다.

## 다듬거나 기억할 부분

정수 입력은 nextInt로 바로 읽을 수 있습니다. 한 줄 출력만 하는 printList·printLast를 합치고 첫 값 이후에 공백을 두면 반복 흐름이 단순해집니다.

## 개선 예시 코드

설명한 개선을 적용한 완전한 Java 실행 코드입니다. 원래 제출 소스는 변경하지 않습니다.

```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        int n = scanner.nextInt();
        for (int i = 1; i <= n; ++i) {
            if (i > 1) System.out.print(" ");
            System.out.print(i);
        }
    }
}
```

## 작은 값으로 따라가기

n=3이면 '1', 공백+'2', 공백+'3' 순서로 출력하여 1 2 3이 됩니다.

## 복잡도

시간 O(n), 추가 공간 O(1).

## 확인 범위

문서의 예시 코드를 로컬 Java 21 환경에서 컴파일하고, 문제 예제와 별도 확인 입력을 합해 1건의 출력을 대조했습니다. 비교 시 줄 끝 공백과 마지막 줄바꿈만 무시했습니다. 위 값 변화 설명은 코드 흐름을 수작업으로 추적한 내용입니다. 실행 시간 벤치마크나 코드트리 재제출은 하지 않았습니다.
