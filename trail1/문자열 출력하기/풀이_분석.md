## 현재 풀이와 좋은 점

고정 문자열을 N번 줄마다 출력합니다. 입력 N을 변경하지 않고 반복변수를 분리했습니다.

## 다듬거나 기억할 부분

같은 줄을 N번 출력해야 하므로 반복 구조가 적절합니다. endl 대신 '\n'을 쓰면 매 줄 강제 flush가 필요 없음을 나타낼 수 있지만 이 작은 입력에서 속도 향상을 단정하지 않습니다.

## 복습 예시 코드

현재 풀이 구조를 유지한 완전한 C++ 실행 코드입니다. 원래 제출 소스는 변경하지 않습니다.

```cpp
#include <iostream>
using namespace std;

int main() {
    int N;
    cin >> N;

    for (int i=1; i<=N; i++) {
        cout << "LeebrosCode" << endl;
    }
    return 0;
}
```

## 작은 값으로 따라가기

N=2이면 LeebrosCode가 두 줄 출력됩니다.

## 복잡도

시간 O(N), 추가 공간 O(1).

## 확인 범위

문서의 예시 코드를 로컬 C++17 환경에서 컴파일하고, 문제 예제와 별도 확인 입력을 합해 1건의 출력을 대조했습니다. 비교 시 줄 끝 공백과 마지막 줄바꿈만 무시했습니다. 위 값 변화 설명은 코드 흐름을 수작업으로 추적한 내용입니다. 실행 시간 벤치마크나 코드트리 재제출은 하지 않았습니다.
