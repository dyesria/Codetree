## 현재 풀이와 좋은 점

현재 값을 먼저 출력하고 짝수면 3을 더하고 홀수면 2배 합니다. 값의 변화 규칙에 while을 사용한 점이 자연스럽습니다.

## 다듬거나 기억할 부분

sum은 합계가 아니므로 current로 이름을 바꾸면 읽기 좋습니다. 홀수가 아니면 짝수뿐이므로 else if를 else로 줄일 수 있습니다. 출력 후 갱신하는 순서를 유지해야 합니다.

## 개선 예시 코드

설명한 개선을 적용한 완전한 C++ 실행 코드입니다. 원래 제출 소스는 변경하지 않습니다.

```cpp
#include <iostream>
using namespace std;

int main() {
    int a, b;
    cin >> a >> b;
    int current = a;
    bool first = true;
    while (current <= b) {
        if (!first) cout << ' ';
        cout << current;
        first = false;
        if (current % 2 == 0) current += 3;
        else current *= 2;
    }
    return 0;
}
```

## 작은 값으로 따라가기

A=2,B=10이면 2 → 5 → 10 → 13으로 진행해 2 5 10을 출력합니다.

## 복잡도

실제 출력 횟수 T에 대해 시간 O(T), 추가 공간 O(1).

## 확인 범위

문서의 예시 코드를 로컬 C++17 환경에서 컴파일하고, 문제 예제와 별도 확인 입력을 합해 2건의 출력을 대조했습니다. 비교 시 줄 끝 공백과 마지막 줄바꿈만 무시했습니다. 위 값 변화 설명은 코드 흐름을 수작업으로 추적한 내용입니다. 실행 시간 벤치마크나 코드트리 재제출은 하지 않았습니다.
