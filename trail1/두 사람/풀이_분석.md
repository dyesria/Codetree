## 현재 풀이와 좋은 점

각 사람의 나이·성별 조건을 AND로 묶고 두 사람 중 한 명이라도 해당하면 OR로 통과시킵니다.

## 다듬거나 기억할 부분

사람별 괄호 묶음이 올바르게 되어 있습니다. 결과가 1/0이므로 bool을 직접 출력하는 것은 선택 사항입니다.

## 복습 예시 코드

현재 풀이 구조를 유지한 완전한 C++ 실행 코드입니다. 원래 제출 소스는 변경하지 않습니다.

```cpp
#include <iostream>
using namespace std;

int main() {
    int age1; char sex1;
    int age2; char sex2;

    cin >> age1 >> sex1;
    cin >> age2 >> sex2;

    if ((19 <= age1 && sex1 == 'M') ||
        (19 <= age2 && sex2 == 'M')) {
            cout << "1" << endl;
    } else {
        cout << "0" << endl;
    }
    
    return 0;
}
```

## 작은 값으로 따라가기

18 M과 19 M이면 두 번째 사람이 조건을 만족해 1입니다. 20 F와 18 M이면 0입니다.

## 복잡도

시간·추가 공간 O(1).

## 확인 범위

문서의 예시 코드를 로컬 C++17 환경에서 컴파일하고, 문제 예제와 별도 확인 입력을 합해 2건의 출력을 대조했습니다. 비교 시 줄 끝 공백과 마지막 줄바꿈만 무시했습니다. 위 값 변화 설명은 코드 흐름을 수작업으로 추적한 내용입니다. 실행 시간 벤치마크나 코드트리 재제출은 하지 않았습니다.
