## 문제

$N$ 개의 정수가 주어질 때, 이 중 홀수이면서 동시에 $3$의 배수인 수들의 총합을 구하는 프로그램을 작성해보세요.

## 입력

첫 줄에 정수 $N$이 주어집니다.

그다음 줄부터 $N$ 개의 줄에 걸쳐, 한 줄에 정수가 하나씩 주어집니다.

## 제한 조건

- $1 \le N \le 10$
- $1 \le \texttt{정수} \le 100$

## 출력

첫 줄에 총합을 출력합니다.

## 입력 예제

### 예제 1

입력

```text
1
6
```

출력

```text
0
```

### 예제 2

입력

```text
2
3
9
```

출력

```text
12
```

### 예제 3

입력

```text
5
2
7
3
9
4
```

출력

```text
12
```
