## 현재 풀이와 좋은 점

10000*w/(h*h)를 계산해 정수 부분을 출력하고 25 이상인지 확인합니다. 문제는 버림한 정수 출력을 요구합니다.

## 다듬거나 기억할 부분

오른쪽 피연산자가 모두 int라 나눗셈은 이미 정수 나눗셈입니다. double에 담아도 잘린 소수부가 복원되지 않습니다. 이 문제에서는 양수이고 기준 25도 정수이므로 판정 결과에 문제가 없습니다. 정수 계산임을 변수 자료형으로 명시할 수 있습니다.

## 개선 예시 코드

설명한 개선을 적용한 완전한 C++ 실행 코드입니다. 원래 제출 소스는 변경하지 않습니다.

```cpp
#include <iostream>
using namespace std;

int main() {
    int height, weight;
    cin >> height >> weight;
    int bmi = 10000 * weight / (height * height);
    cout << bmi << '\n';
    if (bmi >= 25) cout << "Obesity";
    return 0;
}
```

## 작은 값으로 따라가기

h=178,w=88이면 880000/31684의 정수 몫 27을 출력합니다. 25 이상이므로 두 번째 줄에 Obesity를 출력합니다.

## 복잡도

시간·추가 공간 O(1).

## 확인 범위

문서의 예시 코드를 로컬 C++17 환경에서 컴파일하고, 문제 예제와 별도 확인 입력을 합해 2건의 출력을 대조했습니다. 비교 시 줄 끝 공백과 마지막 줄바꿈만 무시했습니다. 위 값 변화 설명은 코드 흐름을 수작업으로 추적한 내용입니다. 실행 시간 벤치마크나 코드트리 재제출은 하지 않았습니다.
