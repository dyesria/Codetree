## 현재 풀이와 좋은 점

A가 양수일 때만 A를 B번 이어 출력하고, 그렇지 않으면 0을 출력합니다. 반복 전에 조건을 한 번 검사합니다.

## 다듬거나 기억할 부분

현재 구조가 이미 적절합니다. A*B를 출력하는 것은 반복된 문자열과 의미가 다르므로 대체하면 안 됩니다.

## 복습 예시 코드

현재 풀이 구조를 유지한 완전한 C++ 실행 코드입니다. 원래 제출 소스는 변경하지 않습니다.

```cpp
#include <iostream>
using namespace std;

int main() {
    int A; int B;
    cin >> A >> B;

    if (0 < A) {
        for (int i=1; i<=B; i++) {
            cout << A;
        }
    } else {
        cout << 0;
    }
    return 0;
}
```

## 작은 값으로 따라가기

A=2,B=3이면 222이며 6이 아닙니다. A=0이면 반복하지 않고 0 하나를 출력합니다.

## 복잡도

양수 분기 시간 O(B), 그 외 O(1), 추가 공간 O(1).

## 확인 범위

문서의 예시 코드를 로컬 C++17 환경에서 컴파일하고, 문제 예제와 별도 확인 입력을 합해 2건의 출력을 대조했습니다. 비교 시 줄 끝 공백과 마지막 줄바꿈만 무시했습니다. 위 값 변화 설명은 코드 흐름을 수작업으로 추적한 내용입니다. 실행 시간 벤치마크나 코드트리 재제출은 하지 않았습니다.
