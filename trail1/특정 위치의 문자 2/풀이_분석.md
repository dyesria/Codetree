## 현재 풀이와 좋은 점

입력 줄을 읽고 2·5·8번째 문자를 3칸 배열에 저장합니다. 필요한 위치만 골라 보관한 점이 좋습니다.

## 다듬거나 기억할 부분

cin >> ch도 공백을 건너뛰어 문자 하나씩 읽습니다. 세 번의 유사한 if를 position % 3 == 2로 표현할 수 있으나, 8번째까지라는 범위를 함께 두어야 합니다. 아래는 10개 문자 입력과 배열 학습을 유지합니다.

## 개선 예시 코드

설명한 개선을 적용한 완전한 C++ 실행 코드입니다. 원래 제출 소스는 변경하지 않습니다.

```cpp
#include <iostream>
using namespace std;

int main() {
    char selected[3];
    int count = 0;
    for (int position = 1; position <= 10; ++position) {
        char ch;
        cin >> ch;
        if (position <= 8 && position % 3 == 2) {
            selected[count++] = ch;
        }
    }
    cout << selected[0] << ' ' << selected[1] << ' ' << selected[2];
    return 0;
}
```

## 작은 값으로 따라가기

A B C D E F G H I J라면 위치 2, 5, 8에서 B, E, H를 골라 B E H를 출력합니다.

## 복잡도

고정 10개라 시간·추가 공간 O(1).

## 확인 범위

문서의 예시 코드를 로컬 C++17 환경에서 컴파일하고, 문제 예제와 별도 확인 입력을 합해 2건의 출력을 대조했습니다. 비교 시 줄 끝 공백과 마지막 줄바꿈만 무시했습니다. 위 값 변화 설명은 코드 흐름을 수작업으로 추적한 내용입니다. 실행 시간 벤치마크나 코드트리 재제출은 하지 않았습니다.
