## 현재 풀이와 좋은 점

A부터 B까지 매번 현재 수를 더합니다. sum을 반복문 바깥에 둬 누적값을 유지했습니다.

## 다듬거나 기억할 부분

현재 반복문은 간결합니다. 같은 수를 입력받아도 한 번 계산해야 하므로 i <= B가 핵심입니다. 선택적 대안은 1LL * (A + B) * (B - A + 1) / 2이며 시간 O(1)입니다. 현재 제한에서는 int로 충분하고, 큰 범위로 확장할 때만 곱셈 자료형을 검토하면 됩니다.

## 복습 예시 코드

현재 풀이 구조를 유지한 완전한 C++ 실행 코드입니다. 원래 제출 소스는 변경하지 않습니다.

```cpp
#include <iostream>
using namespace std;

int main() {
    int A, B;
    int sum = 0;
    cin >> A >> B;

    for (int i=A; i<=B; i++) {
        sum += i;
    }

    cout << sum;
    return 0;
}
```

## 작은 값으로 따라가기

A=2, B=5이면 sum: 0 → 2 → 5 → 9 → 14. A=B=5이면 결과 5입니다.

## 복잡도

시간 O(B-A+1), 추가 공간 O(1).

## 확인 범위

문서의 예시 코드를 로컬 C++17 환경에서 컴파일하고, 문제 예제와 별도 확인 입력을 합해 2건의 출력을 대조했습니다. 비교 시 줄 끝 공백과 마지막 줄바꿈만 무시했습니다. 위 값 변화 설명은 코드 흐름을 수작업으로 추적한 내용입니다. 실행 시간 벤치마크나 코드트리 재제출은 하지 않았습니다.
