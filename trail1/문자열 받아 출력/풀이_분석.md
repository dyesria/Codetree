## 현재 풀이와 좋은 점

string으로 단어 하나를 읽고 그대로 출력합니다.

## 다듬거나 기억할 부분

string을 사용하므로 <string> 헤더를 직접 포함하면 사용하는 표준 기능의 의존성이 명확해집니다. 단어 입력인 현재 요구에는 >>가 적절합니다.

## 복습 예시 코드

현재 풀이 구조를 유지한 완전한 C++ 실행 코드입니다. 원래 제출 소스는 변경하지 않습니다.

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string S;
    cin >> S;
    cout << S;
    return 0;
}
```

## 작은 값으로 따라가기

Hello를 읽으면 S 전체가 Hello이며 그대로 출력합니다.

## 복잡도

문자열 길이 L에 대해 시간 O(L), 저장 공간 O(L).

## 확인 범위

문서의 예시 코드를 로컬 C++17 환경에서 컴파일하고, 문제 예제와 별도 확인 입력을 합해 2건의 출력을 대조했습니다. 비교 시 줄 끝 공백과 마지막 줄바꿈만 무시했습니다. 위 값 변화 설명은 코드 흐름을 수작업으로 추적한 내용입니다. 실행 시간 벤치마크나 코드트리 재제출은 하지 않았습니다.
