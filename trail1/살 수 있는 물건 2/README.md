## 문제

$N$만큼의 돈으로 살 수 있는 물건 중 가장 비싼 물건을 출력하는 프로그램을 작성해보세요.

```text
물건   가격

book  3000
mask  1000
pen    500

```

## 입력

첫 번째 줄에 가지고 있는 돈 $N$이 주어집니다.

## 제한 조건

- $0 \le N \le 10\,000$

## 출력

첫 번째 줄에  살 수 있는 가장 비싼 물건의 이름을 출력합니다. 만약, 아무것도 살 수 없다면 `no` 를 출력합니다.

## 입력 예제

### 예제 1

입력

```text
3000
```

출력

```text
book
```

### 예제 2

입력

```text
1000
```

출력

```text
mask
```

### 예제 3

입력

```text
300
```

출력

```text
no
```
