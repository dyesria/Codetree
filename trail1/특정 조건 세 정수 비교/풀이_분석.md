## 현재 풀이와 좋은 점

최솟값을 찾은 뒤 a가 그 값인지, 세 값이 모두 같은지를 따로 출력합니다.

## 다듬거나 기억할 부분

a가 최솟값인지 확인하려면 a<=b && a<=c로 직접 표현할 수도 있습니다. 최솟값 자체가 필요 없는 이 문제에서는 low 누적을 생략할 수 있습니다.

## 복습 예시 코드

현재 풀이 구조를 유지한 완전한 C++ 실행 코드입니다. 원래 제출 소스는 변경하지 않습니다.

```cpp
#include <iostream>
using namespace std;

int main() {
    int a; int b; int c;
    int low;

    cin >> a >> b >> c;

    low = a;
    if (b<low) {
        low = b;
    } 
    if (c<low) {
        low = c;
    }

// --------------- 출력부----------------
    if (a == low) {
        cout << "1";
    } else {
        cout << "0";
    }

    cout << " ";

    if (a == b && b == c) {
        cout << "1";
    } else {
        cout << "0";
    }

    return 0;
}
```

## 작은 값으로 따라가기

a=2,b=2,c=3이면 a도 최솟값이므로 첫 값 1, 모두 같지는 않아 두 번째 값 0입니다.

## 복잡도

시간·추가 공간 O(1).

## 확인 범위

문서의 예시 코드를 로컬 C++17 환경에서 컴파일하고, 문제 예제와 별도 확인 입력을 합해 2건의 출력을 대조했습니다. 비교 시 줄 끝 공백과 마지막 줄바꿈만 무시했습니다. 위 값 변화 설명은 코드 흐름을 수작업으로 추적한 내용입니다. 실행 시간 벤치마크나 코드트리 재제출은 하지 않았습니다.
