## 현재 풀이와 좋은 점

배열의 인덱스 2, 4, 9를 골라 더합니다. 문제의 3·5·10번째 위치를 0부터 시작하는 인덱스로 변환했습니다.

## 다듬거나 기억할 부분

isTrue는 무엇이 true인지 알기 어려운 이름입니다. isTargetIndex 같은 이름이나 position==3 || position==5 || position==10이 더 직접적입니다. 아래는 배열 연습을 유지합니다.

## 개선 예시 코드

설명한 개선을 적용한 완전한 Java 실행 코드입니다. 원래 제출 소스는 변경하지 않습니다.

```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        int[] values = new int[10];
        int sum = 0;
        for (int i = 0; i < values.length; ++i) {
            values[i] = scanner.nextInt();
            int position = i + 1;
            if (position == 3 || position == 5 || position == 10) {
                sum += values[i];
            }
        }
        System.out.print(sum);
    }
}
```

## 작은 값으로 따라가기

1~10을 넣으면 선택한 값은 3, 5, 10이고 누적 합은 3 → 8 → 18입니다.

## 복잡도

고정 10개라 시간·공간 O(1). K개로 일반화한 배열 저장은 시간·공간 O(K).

## 확인 범위

문서의 예시 코드를 로컬 Java 21 환경에서 컴파일하고, 문제 예제와 별도 확인 입력을 합해 2건의 출력을 대조했습니다. 비교 시 줄 끝 공백과 마지막 줄바꿈만 무시했습니다. 위 값 변화 설명은 코드 흐름을 수작업으로 추적한 내용입니다. 실행 시간 벤치마크나 코드트리 재제출은 하지 않았습니다.
