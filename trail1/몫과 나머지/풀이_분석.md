## 현재 풀이와 좋은 점

정수 나눗셈과 나머지 연산을 출력 구분자 ... 사이에 배치합니다.

## 다듬거나 기억할 부분

a / b와 a % b에 공백을 넣으면 수식 구분이 조금 더 쉽습니다. 알고리즘은 이미 최소한의 연산입니다.

## 복습 예시 코드

현재 풀이 구조를 유지한 완전한 C++ 실행 코드입니다. 원래 제출 소스는 변경하지 않습니다.

```cpp
#include <iostream>
using namespace std;

int main() {
    int a; int b;
    cin >> a >> b;
    cout << a/b << "..." << a%b;
    return 0;
}
```

## 작은 값으로 따라가기

17=5×3+2이므로 a=17,b=5에서 3...2가 출력됩니다.

## 복잡도

시간·추가 공간 O(1).

## 확인 범위

문서의 예시 코드를 로컬 C++17 환경에서 컴파일하고, 문제 예제와 별도 확인 입력을 합해 1건의 출력을 대조했습니다. 비교 시 줄 끝 공백과 마지막 줄바꿈만 무시했습니다. 위 값 변화 설명은 코드 흐름을 수작업으로 추적한 내용입니다. 실행 시간 벤치마크나 코드트리 재제출은 하지 않았습니다.
