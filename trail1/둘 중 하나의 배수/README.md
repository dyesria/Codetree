## 문제

정수 $A$가 주어졌을 때, $A$가 $3$의 배수이거나 $5$의 배수인 경우에는 $1$을, 그렇지 않다면 $0$을 출력하는 프로그램을 작성해보세요.

## 입력

첫 번째 줄에 정수 $A$가 주어집니다.

## 제한 조건

- $1 \le A \le 1\,000$

## 출력

첫 번째 줄에 $A$가 $3$의 배수이거나 $5$의 배수인 경우에는 $1$을, 그렇지 않다면 $0$을 출력합니다.

## 입력 예제

### 예제 1

입력

```text
9
```

출력

```text
1
```

### 예제 2

입력

```text
2
```

출력

```text
0
```
