## 현재 풀이와 좋은 점

2월을 먼저 처리하고 31일인 달을 나열한 뒤 나머지를 30일로 처리합니다.

## 다듬거나 기억할 부분

서로 배타적인 세 경우로 나눈 구조가 명확합니다. 달별 일수 배열은 가능한 대안이지만 조건문 연습에서는 현재 방식도 적절합니다.

## 복습 예시 코드

현재 풀이 구조를 유지한 완전한 C++ 실행 코드입니다. 원래 제출 소스는 변경하지 않습니다.

```cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;

    if (n == 2) {
        cout << "28";
    } else if (n == 1 || n == 3 || n == 5 || n == 7 || n == 8 || n == 10 || n == 12) {
        cout << "31";
    } else {
        cout << "30";
    }
    return 0;
}
```

## 작은 값으로 따라가기

2월→28, 8월→31, 9월→30입니다. 이 문제에는 윤년 계산을 임의로 추가하지 않습니다.

## 복잡도

시간·추가 공간 O(1).

## 확인 범위

문서의 예시 코드를 로컬 C++17 환경에서 컴파일하고, 문제 예제와 별도 확인 입력을 합해 2건의 출력을 대조했습니다. 비교 시 줄 끝 공백과 마지막 줄바꿈만 무시했습니다. 위 값 변화 설명은 코드 흐름을 수작업으로 추적한 내용입니다. 실행 시간 벤치마크나 코드트리 재제출은 하지 않았습니다.
