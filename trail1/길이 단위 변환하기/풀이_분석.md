## 현재 풀이와 좋은 점

단위를 곱으로 변환하고 fixed와 precision(1)로 소수 한 자리를 출력합니다.

## 다듬거나 기억할 부분

ft와 mi에는 이미 cm로 변환한 결과가 들어갑니다. feetInCm, milesInCm처럼 결과 단위를 이름에 담으면 더 명확합니다.

## 복습 예시 코드

현재 풀이 구조를 유지한 완전한 C++ 실행 코드입니다. 원래 제출 소스는 변경하지 않습니다.

```cpp
#include <iostream>
using namespace std;

int main() {
    double ft = 9.2 * 30.48;
    double mi = 1.3 * 160934;

    cout << fixed;

    cout.precision(1);
    
    cout << "9.2ft = " << ft << "cm" << endl
         << "1.3mi = " << mi << "cm" << endl;

    return 0;
}
```

## 작은 값으로 따라가기

9.2×30.48=280.416은 280.4, 1.3×160934=209214.2는 그대로 소수 한 자리로 표시합니다.

## 복잡도

시간·추가 공간 O(1).

## 확인 범위

문서의 예시 코드를 로컬 C++17 환경에서 컴파일하고, 문제 예제와 별도 확인 입력을 합해 1건의 출력을 대조했습니다. 비교 시 줄 끝 공백과 마지막 줄바꿈만 무시했습니다. 위 값 변화 설명은 코드 흐름을 수작업으로 추적한 내용입니다. 실행 시간 벤치마크나 코드트리 재제출은 하지 않았습니다.
