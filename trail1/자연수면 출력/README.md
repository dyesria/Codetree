## 문제

두 정수 $A$와 $B$를 입력받아, $A$가 양수라면 $A$를 $B$번 반복하여 출력하는 프로그램을 작성해보세요.

## 입력

첫 번째 줄에 정수 $A$와 $B$가 공백을 두고 주어집니다.

## 제한 조건

- $-9 \le A \le 9$
- $1 \le B \le 50$

## 출력

첫 번째 줄에 $A$가 양수라면 $A$를 $B$번 반복하여 공백없이 출력합니다.

만약 $A$가 $0$이하라면 $0$을 출력합니다.

## 입력 예제

### 예제 1

입력

```text
2 3
```

출력

```text
222
```

### 예제 2

입력

```text
-2 3
```

출력

```text
0
```
