## 문제

두 정수 $A, B$를 입력받아 다음 값들을 전부 계산해서 출력하는 프로그램을 작성해보세요.

- 두 정수를 더했을 때의 결과
- $A$에서 $B$를 뺐을 때의 결과
- $A$를 $B$로 나누었을 때의 몫
- $A$를 $B$로 나누었을 때의 나머지

## 입력

첫 번째 줄에 정수 $A$, $B$가 공백을 사이에 두고 주어집니다.

## 제한 조건

$1 \le A,\ B \le 100$

## 출력

첫 번째 줄에는 두 정수를 더했을 때의 결과,

두 번째 줄에는 $A$에서 $B$를 뺐을 때의 결과,

세 번째 줄에는 $A$를 $B$로 나누었을 때의 몫,

네 번째 줄에는 $A$를 $B$로 나누었을 때의 나머지를 출력합니다.

## 입력 예제

### 예제 1

입력

```text
2 5
```

출력

```text
7
-3
0
2
```

### 예제 2

입력

```text
7 3
```

출력

```text
10
4
2
1
```
