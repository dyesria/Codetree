## 현재 풀이와 좋은 점

바깥 반복으로 행, 안쪽 반복으로 열을 출력합니다. 함수에 높이·너비를 전달하는 구조가 적절합니다.

## 다듬거나 기억할 부분

두 반복변수 이름이 모두 i라 안쪽 변수가 바깥 변수를 가립니다. row와 col로 바꾸고 전역 n,m을 지역변수로 옮기면 어느 방향을 반복하는지 바로 읽힙니다.

## 개선 예시 코드

설명한 개선을 적용한 완전한 C++ 실행 코드입니다. 원래 제출 소스는 변경하지 않습니다.

```cpp
#include <iostream>
using namespace std;

void printRectangle(int rows, int cols) {
    for (int row = 0; row < rows; ++row) {
        for (int col = 0; col < cols; ++col) cout << '1';
        cout << '\n';
    }
}

int main() {
    int n, m;
    cin >> n >> m;
    printRectangle(n, m);
    return 0;
}
```

## 작은 값으로 따라가기

n=2,m=3이면 안쪽에서 111 출력 후 줄바꿈을 두 번 수행하여 2행 3열이 됩니다.

## 복잡도

시간 O(nm), 추가 공간 O(1). 필요한 출력량이 nm이므로 반복 횟수 자체는 적절합니다.

## 확인 범위

문서의 예시 코드를 로컬 C++17 환경에서 컴파일하고, 문제 예제와 별도 확인 입력을 합해 1건의 출력을 대조했습니다. 비교 시 줄 끝 공백과 마지막 줄바꿈만 무시했습니다. 위 값 변화 설명은 코드 흐름을 수작업으로 추적한 내용입니다. 실행 시간 벤치마크나 코드트리 재제출은 하지 않았습니다.
