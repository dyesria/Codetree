## 문제

감기 증상이 있으면 `Y`, 없으면 `N`으로 나타내기로 하고, 증상 여부와 체온에 따라 진료소를 다음과 같이 구분하려고 합니다.

- 증상이 있고, 체온이 $37$℃ 이상일 때 `A`
- 증상이 없고, 체온이 $37$℃ 이상일 때 `B`
- 증상이 있고, 체온이 $37$℃ 미만일 때 `C`
- 증상이 없고, 체온이 $37$℃ 미만일 때 `D`

한 번에 $3$명씩 검사하는데 `A`로 가는 사람이 $2$명 이상 나올 때는 위급상황으로 분류합니다. 위급상황인지를 판단하는 프로그램을 작성해보세요.

## 입력

첫 번째 줄부터 $3$개의 줄에 걸쳐, $1$줄에 $1$명씩 총 $3$명의 감기 증상과 체온이 공백을 사이에 두고 주어집니다. 감기 증상은 항상 `Y` 또는 `N`으로 주어진다 가정해도 좋습니다. 체온은 정수로 주어집니다.

## 제한 조건

- $0 \le \texttt{주어지는 체온} \le 40$

## 출력

위급상황이라면 `E`를, 그렇지 않다면 `N`을 출력합니다.

## 입력 예제

### 예제 1

입력

```text
Y 38
N 36
Y 40
```

출력

```text
E
```

### 예제 2

입력

```text
Y 36
Y 37
N 37
```

출력

```text
N
```
