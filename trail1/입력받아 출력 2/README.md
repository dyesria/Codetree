## 문제

`OOOOOO-OOOOOOO` 형식으로 이루어져 있는 주민번호를 입력받아, `-`를 제외하여 출력하는 프로그램을 작성해보세요.

## 입력

첫 번째 줄에 주민번호가 `OOOOOO-OOOOOOO` 형태로 주어집니다. 앞은 $6$자리, 뒤는 $7$자리로 숫자로 이루어져 있습니다. 앞, 뒤 모두 맨 앞 숫자가 $0$으로 주어지는 경우는 없다고 가정해도 좋습니다.

## 출력

입력받은 주민번호에서 `-`를 제외한 결과를 출력합니다.

## 입력 예제

### 예제 1

입력

```text
940312-1082836
```

출력

```text
9403121082836
```
