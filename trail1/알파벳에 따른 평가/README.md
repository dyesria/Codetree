## 문제

영문 대문자를 입력받아

$S$이면 `Superior`,

$A$이면 `Excellent`,

$B$이면 `Good`,

$C$이면 `Usually`,

$D$이면 `Effort`,

그 외 문자이면 `Failure` 라고 출력하는 프로그램을 작성해주세요.

## 입력

문자 하나가 주어집니다.

## 출력

입력받은 문자에 따른 평가를 문자열로 출력하세요.

## 입력 예제

### 예제 1

입력

```text
C
```

출력

```text
Usually
```

### 예제 2

입력

```text
Z
```

출력

```text
Failure
```
