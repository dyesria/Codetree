## 현재 풀이와 좋은 점

출력 형식을 한 번 설정하고 세 값을 줄마다 소수 세 자리로 표시합니다.

## 다듬거나 기억할 부분

형식을 출력마다 반복 설정하지 않은 점이 좋습니다. precision은 변수 자체의 값을 바꾸지 않습니다.

## 복습 예시 코드

현재 풀이 구조를 유지한 완전한 C++ 실행 코드입니다. 원래 제출 소스는 변경하지 않습니다.

```cpp
#include <iostream>
using namespace std;

int main() {
    double a; double b; double c;

    cin >> a >> b >> c;

    cout << fixed;
    cout.precision(3);

    cout << a << endl
         << b << endl
         << c << endl;
    return 0;
}
```

## 작은 값으로 따라가기

1.2346을 표시하면 1.235이며 원래 변수의 저장값을 1.235로 대입한 것은 아닙니다.

## 복잡도

시간·추가 공간 O(1).

## 확인 범위

문서의 예시 코드를 로컬 C++17 환경에서 컴파일하고, 문제 예제와 별도 확인 입력을 합해 1건의 출력을 대조했습니다. 비교 시 줄 끝 공백과 마지막 줄바꿈만 무시했습니다. 위 값 변화 설명은 코드 흐름을 수작업으로 추적한 내용입니다. 실행 시간 벤치마크나 코드트리 재제출은 하지 않았습니다.
