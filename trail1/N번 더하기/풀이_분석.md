## 현재 풀이와 좋은 점

초기값 A에서 시작하여 N을 더한 뒤 출력하는 일을 N번 반복합니다. 덧셈 후 출력하는 순서가 요구에 맞습니다.

## 다듬거나 기억할 부분

sum=0 뒤 sum+=A를 쓰기보다 current=A로 초기화하면 현재 수라는 역할이 명확해집니다. 매번 출력해야 하므로 반복을 없애는 최적화는 필요하지 않습니다.

## 개선 예시 코드

설명한 개선을 적용한 완전한 C++ 실행 코드입니다. 원래 제출 소스는 변경하지 않습니다.

```cpp
#include <iostream>
using namespace std;

int main() {
    int a, n;
    cin >> a >> n;
    int current = a;
    for (int i = 0; i < n; ++i) {
        current += n;
        cout << current << '\n';
    }
    return 0;
}
```

## 작은 값으로 따라가기

A=3,N=2이면 current=3 → 5(출력) → 7(출력)입니다. 시작값 3은 출력하지 않습니다.

## 복잡도

시간 O(N), 추가 공간 O(1).

## 확인 범위

문서의 예시 코드를 로컬 C++17 환경에서 컴파일하고, 문제 예제와 별도 확인 입력을 합해 1건의 출력을 대조했습니다. 비교 시 줄 끝 공백과 마지막 줄바꿈만 무시했습니다. 위 값 변화 설명은 코드 흐름을 수작업으로 추적한 내용입니다. 실행 시간 벤치마크나 코드트리 재제출은 하지 않았습니다.
