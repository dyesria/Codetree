## 현재 풀이와 좋은 점

A<B와 B<C를 동시에 확인해 순서가 맞는지 1/0으로 출력합니다.

## 다듬거나 기억할 부분

이 문제는 세 수를 정렬해 중앙값 자체를 출력하는 문제가 아닙니다. 현재 요구에 맞는 두 비교를 유지하세요.

## 복습 예시 코드

현재 풀이 구조를 유지한 완전한 C++ 실행 코드입니다. 원래 제출 소스는 변경하지 않습니다.

```cpp
#include <iostream>
using namespace std;

int main() {
    int A; int B; int C;
    cin >> A >> B >> C;
    
    if (A<B && B<C) {
        cout << "1";
    } else {
        cout << "0";
    }

    return 0;
}
```

## 작은 값으로 따라가기

A=1,B=2,C=3이면 1, A=3,B=2,C=1이면 0입니다.

## 복잡도

시간·추가 공간 O(1).

## 확인 범위

문서의 예시 코드를 로컬 C++17 환경에서 컴파일하고, 문제 예제와 별도 확인 입력을 합해 2건의 출력을 대조했습니다. 비교 시 줄 끝 공백과 마지막 줄바꿈만 무시했습니다. 위 값 변화 설명은 코드 흐름을 수작업으로 추적한 내용입니다. 실행 시간 벤치마크나 코드트리 재제출은 하지 않았습니다.
