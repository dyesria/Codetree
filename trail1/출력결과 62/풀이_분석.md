## 핵심 원리

int와 double을 더하면 실수 덧셈이 되고 결과를 소수 두 자리로 출력합니다.

## 순서대로 따라가기

1 + 1.3 = 2.3이며 출력 형식은 2.30입니다.

## 기억할 부분

수의 값 2.3과 표시 문자열 2.30은 구분됩니다. 소수 두 자리를 요구하면 뒤 0도 출력해야 합니다.

## 복습 예시 코드

제시 코드를 C++에서 확인하기 위한 완전한 실행 예시입니다. 필요한 main·출력을 보충하거나 위 설명에 맞게 정리했습니다.

```cpp
#include <iostream>
using namespace std;

int main() {
    cout << fixed;
    int a = 1; 
    double b = 1.3; 
    double c;
    c = a + b; 
    cout.precision(2);
    cout << c << endl;
    return 0;
}
```

## 복잡도

시간·공간 O(1).

## 확인 범위

문서의 예시 코드를 로컬 C++17 환경에서 컴파일하고, 복습 확인 입력 1건의 출력을 대조했습니다. 비교 시 줄 끝 공백과 마지막 줄바꿈만 무시했습니다. 위 값 변화 설명은 코드 흐름을 수작업으로 추적한 내용입니다. 실행 시간 벤치마크나 코드트리 재제출은 하지 않았습니다.
