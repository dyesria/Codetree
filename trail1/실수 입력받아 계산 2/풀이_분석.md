## 현재 풀이와 좋은 점

입력 실수에 1.5를 더하고 소수 두 자리로 표시합니다.

## 다듬거나 기억할 부분

연산을 한 번만 수행하는 간결한 풀이입니다. 1.5가 실수 리터럴이라 소수 부분을 유지합니다.

## 복습 예시 코드

현재 풀이 구조를 유지한 완전한 C++ 실행 코드입니다. 원래 제출 소스는 변경하지 않습니다.

```cpp
#include <iostream>
using namespace std;

int main() {
    double a;
    cin >> a;

    cout << fixed;
    cout.precision(2);

    cout << a + 1.5;

    return 0;
}
```

## 작은 값으로 따라가기

2.25 + 1.5 = 3.75입니다.

## 복잡도

시간·추가 공간 O(1).

## 확인 범위

문서의 예시 코드를 로컬 C++17 환경에서 컴파일하고, 문제 예제와 별도 확인 입력을 합해 1건의 출력을 대조했습니다. 비교 시 줄 끝 공백과 마지막 줄바꿈만 무시했습니다. 위 값 변화 설명은 코드 흐름을 수작업으로 추적한 내용입니다. 실행 시간 벤치마크나 코드트리 재제출은 하지 않았습니다.
