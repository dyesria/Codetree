## 핵심 원리

1~60 중 60을 나누어떨어지게 하는 수를 셉니다. b는 약수의 합이 아닌 개수입니다.

## 순서대로 따라가기

약수는 1,2,3,4,5,6,10,12,15,20,30,60으로 12개입니다.

## 기억할 부분

더 큰 n에서는 i와 n/i를 한 쌍으로 보아 제곱근까지만 검사할 수 있습니다. 완전제곱수의 가운데 약수는 한 번만 세어야 합니다.

## 복습 예시 코드

제시 코드를 C++에서 확인하기 위한 완전한 실행 예시입니다. 필요한 main·출력을 보충하거나 위 설명에 맞게 정리했습니다.

```cpp
#include <iostream>
using namespace std;

int main() {
    int a = 60, b = 0; 
    for (int i = 1; i <= a; i++) {
        if (a % i == 0)
            b++;
    }
    cout << b;
    return 0;
}
```

## 복잡도

일반 n에서 현재 시간 O(n), 추가 공간 O(1). 약수 쌍 대안은 시간 O(√n).

## 확인 범위

문서의 예시 코드를 로컬 C++17 환경에서 컴파일하고, 복습 확인 입력 1건의 출력을 대조했습니다. 비교 시 줄 끝 공백과 마지막 줄바꿈만 무시했습니다. 위 값 변화 설명은 코드 흐름을 수작업으로 추적한 내용입니다. 실행 시간 벤치마크나 코드트리 재제출은 하지 않았습니다.
