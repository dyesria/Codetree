## 현재 풀이와 좋은 점

고정 문자열 7 + 23 = 30을 직접 출력해 요구되는 화면 결과를 만듭니다.

## 다듬거나 기억할 부분

원문은 세 정수형 변수를 선언하고 대입한 뒤 활용하는 연습입니다. 출력만 맞추는 것과 변수 연습을 하는 것은 구분할 필요가 있습니다. 아래처럼 세 변수를 실제 출력에 사용해 보는 것이 좋습니다.

## 개선 예시 코드

설명한 개선을 적용한 완전한 C++ 실행 코드입니다. 원래 제출 소스는 변경하지 않습니다.

```cpp
#include <iostream>
using namespace std;

int main() {
    int a = 7, b = 23, c = 30;
    cout << a << " + " << b << " = " << c;
    return 0;
}
```

## 작은 값으로 따라가기

a=7,b=23,c=30을 차례로 문자열 기호 사이에 넣어 7 + 23 = 30을 만듭니다.

## 복잡도

시간·추가 공간 O(1).

## 확인 범위

문서의 예시 코드를 로컬 C++17 환경에서 컴파일하고, 문제 예제와 별도 확인 입력을 합해 1건의 출력을 대조했습니다. 비교 시 줄 끝 공백과 마지막 줄바꿈만 무시했습니다. 위 값 변화 설명은 코드 흐름을 수작업으로 추적한 내용입니다. 실행 시간 벤치마크나 코드트리 재제출은 하지 않았습니다.
