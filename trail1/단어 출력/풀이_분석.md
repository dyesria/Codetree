## 현재 풀이와 좋은 점

Hello을 고정된 형식으로 출력합니다. 필요한 문자열을 직접 표현한 간결한 풀이입니다.

## 다듬거나 기억할 부분

이 문제는 고정 출력 연습이라 알고리즘 최적화가 필요하지 않습니다. 출력할 공백·줄바꿈·문장부호를 확인하는 것이 핵심입니다.

## 복습 예시 코드

현재 풀이 구조를 유지한 완전한 Java 실행 코드입니다. 원래 제출 소스는 변경하지 않습니다.

```java
public class Main {
    public static void main(String[] args) {
        System.out.print("Hello");
    }
}
```

## 작은 값으로 따라가기

System.out.print는 문자열을 출력하고 자동 줄바꿈을 붙이지 않습니다.

## 복잡도

출력 길이가 고정되어 시간·추가 공간 O(1).

## 확인 범위

문서의 예시 코드를 로컬 Java 21 환경에서 컴파일하고, 문제 예제와 별도 확인 입력을 합해 1건의 출력을 대조했습니다. 비교 시 줄 끝 공백과 마지막 줄바꿈만 무시했습니다. 위 값 변화 설명은 코드 흐름을 수작업으로 추적한 내용입니다. 실행 시간 벤치마크나 코드트리 재제출은 하지 않았습니다.
