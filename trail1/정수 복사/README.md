## 문제

변수 $a$에 $3$를 넣고, 변수 $b$에 $4$를 넣은 뒤, 다시 $a$의 값을 $b$에 넣어줍니다. 그 후, $a$와 $b$의 값을 곱한 결과값을 출력합니다.

## 입력

입력이 주어지지 않습니다.

## 출력

첫 번째 줄에 계산이 끝난 뒤의 $a$값과 $b$값을 공백을 두고 출력합니다.

두 번째 줄에 $a$와 $b$를 곱한 값을 출력합니다.

## 입력 예제

### 예제 1

출력

```text
3 3
9
```
