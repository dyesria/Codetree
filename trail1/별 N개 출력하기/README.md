## 문제

정수 $N$이 주어지면 `*`을 $N$개의 줄에 걸쳐 한 줄에 하나씩 출력하는 프로그램을 작성해보세요.

단, `while` 문을 사용하여 해결해봅니다.

## 입력

첫 번째 줄에 정수 n이 주어집니다.

## 제한 조건

- $1 \le N \le 50$

## 출력

첫 번째 줄부터 $N$개의 줄에 걸쳐, 한 줄에 한 개의 `*` 을 출력합니다.

## 입력 예제

### 예제 1

입력

```text
5
```

출력

```text
*
*
*
*
*
```

## 제한

• Time Limit: 500 ms

• Memory Limit: 64 MiB
