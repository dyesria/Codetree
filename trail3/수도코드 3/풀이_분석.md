## 핵심 원리

배열의 직전 두 값을 더해 다음 값을 채웁니다. 배열 인덱스는 0부터 시작합니다.

## 순서대로 따라가기

| i | 계산 | arr[i] |
|---|---|---:|
| 2 | 1+1 | 2 |
| 3 | 2+1 | 3 |
| 4 | 3+2 | 5 |
| 5 | 5+3 | 8 |

따라서 arr[5]는 8입니다.

## 기억할 부분

현재 반복에서 계산한 값이 다음 반복의 입력이 됩니다. 배열 전체를 처음 상태로 고정해 읽으면 안 됩니다.

## 복습 예시 코드

제시 코드를 C++에서 확인하기 위한 완전한 실행 예시입니다. 필요한 main·출력을 보충하거나 위 설명에 맞게 정리했습니다.

```cpp
#include <iostream>
using namespace std;

int main() {
    int values[6] = {1, 1, 0, 0, 0, 0};
    for (int i = 2; i <= 5; ++i) {
        values[i] = values[i - 1] + values[i - 2];
    }
    cout << values[5];
    return 0;
}
```

## 복잡도

고정 6칸에서는 O(1). N번째 값까지 배열에 채우면 시간·공간 O(N).

## 확인 범위

문서의 예시 코드를 로컬 C++17 환경에서 컴파일하고, 복습 확인 입력 1건의 출력을 대조했습니다. 비교 시 줄 끝 공백과 마지막 줄바꿈만 무시했습니다. 위 값 변화 설명은 코드 흐름을 수작업으로 추적한 내용입니다. 실행 시간 벤치마크나 코드트리 재제출은 하지 않았습니다.
