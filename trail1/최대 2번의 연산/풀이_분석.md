## 현재 풀이와 좋은 점

짝수면 절반으로 만든 뒤 그 결과가 홀수인지 다시 검사합니다.

## 다듬거나 기억할 부분

두 조건은 갱신된 값을 대상으로 순차 실행되어야 합니다. else if로 줄이면 같은 입력에서 두 번 연산할 기회를 잃습니다.

## 복습 예시 코드

현재 풀이 구조를 유지한 완전한 C++ 실행 코드입니다. 원래 제출 소스는 변경하지 않습니다.

```cpp
#include <iostream>
using namespace std;

int main() {
    int a;
    cin >> a;

    if (a % 2 == 0) {
        a /= 2;
    }
    if (a % 2 != 0) {
        a += 1;
        a /= 2;
    }

    cout << a;
    
    return 0;
}
```

## 작은 값으로 따라가기

6 → 첫 if에서 3 → 두 번째 if에서 (3+1)/2=2입니다. 8은 4에서 끝납니다.

## 복잡도

시간·추가 공간 O(1).

## 확인 범위

문서의 예시 코드를 로컬 C++17 환경에서 컴파일하고, 문제 예제와 별도 확인 입력을 합해 2건의 출력을 대조했습니다. 비교 시 줄 끝 공백과 마지막 줄바꿈만 무시했습니다. 위 값 변화 설명은 코드 흐름을 수작업으로 추적한 내용입니다. 실행 시간 벤치마크나 코드트리 재제출은 하지 않았습니다.
