## 문제

정수 $A, B$이 주어졌을 때, $A$부터 $B$까지의 자연수중 짝수만 출력하는 프로그램을 작성해보세요.

단, `while`문을 사용하여 해결해봅니다.

## 입력

첫 번째 줄에 정수 $A$와 $B$가 공백을 두고 주어집니다.

## 제한 조건

- $1 \le A \le B \le 50$
- $A, B$는 짝수

## 출력

첫 번째 줄에 $A$부터 $B$까지의 자연수중 짝수들만 공백을 두고 오름차순으로 출력합니다.

## 입력 예제

### 예제 1

입력

```text
10 20
```

출력

```text
10 12 14 16 18 20
```

## 제한

• Time Limit: 500 ms

• Memory Limit: 64 MiB
