## 현재 풀이와 좋은 점

합을 정수로 출력하고 평균은 형변환 후 2로 나눕니다.

## 다듬거나 기억할 부분

정수 합과 실수 평균을 구별했습니다. sum을 이름으로 빼면 두 번 쓴 A+B를 공유할 수 있지만 필수는 아닙니다.

## 복습 예시 코드

현재 풀이 구조를 유지한 완전한 C++ 실행 코드입니다. 원래 제출 소스는 변경하지 않습니다.

```cpp
#include <iostream>
using namespace std;

int main() {
    cout << fixed;
    cout.precision(1);

    int A; int B;
    cin >> A >> B;

    cout << A+B << ' ' << (double)(A+B) / 2;
    return 0;
}
```

## 작은 값으로 따라가기

A=2,B=3이면 합 5와 평균 2.5를 출력합니다.

## 복잡도

시간·추가 공간 O(1).

## 확인 범위

문서의 예시 코드를 로컬 C++17 환경에서 컴파일하고, 문제 예제와 별도 확인 입력을 합해 2건의 출력을 대조했습니다. 비교 시 줄 끝 공백과 마지막 줄바꿈만 무시했습니다. 위 값 변화 설명은 코드 흐름을 수작업으로 추적한 내용입니다. 실행 시간 벤치마크나 코드트리 재제출은 하지 않았습니다.
