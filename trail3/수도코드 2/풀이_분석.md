## 핵심 원리

i<=9이면 continue로 출력 문장을 건너뜁니다. 반복 전체를 끝내지는 않습니다.

## 순서대로 따라가기

1\~9는 출력 0회, 10\~20은 각 1회이므로 20-10+1=11회입니다.

## 기억할 부분

continue는 다음 반복으로, break는 반복 밖으로 이동합니다. 예시 코드는 원문처럼 CodeTree를 실제로 출력합니다.

## 복습 예시 코드

제시 코드를 C++에서 확인하기 위한 완전한 실행 예시입니다. 필요한 main·출력을 보충하거나 위 설명에 맞게 정리했습니다.

```cpp
#include <iostream>
using namespace std;

int main() {
    for (int i = 1; i <= 20; ++i) {
        if (i <= 9) continue;
        cout << "CodeTree\n";
    }
    return 0;
}
```

## 복잡도

고정 20회에서는 O(1). 상한 N이면 시간 O(N), 추가 공간 O(1).

## 확인 범위

문서의 예시 코드를 로컬 C++17 환경에서 컴파일하고, 복습 확인 입력 1건의 출력을 대조했습니다. 비교 시 줄 끝 공백과 마지막 줄바꿈만 무시했습니다. 위 값 변화 설명은 코드 흐름을 수작업으로 추적한 내용입니다. 실행 시간 벤치마크나 코드트리 재제출은 하지 않았습니다.
