## 현재 풀이와 좋은 점

홀수이면서 3의 배수, 또는 짝수이면서 5의 배수라는 두 묶음을 OR로 연결합니다.

## 다듬거나 기억할 부분

&& 묶음에 괄호를 둔 현재 방식이 읽기 좋습니다. 더 길어지면 oddMultipleOf3 같은 bool 이름을 줄 수 있지만 필수는 아닙니다.

## 복습 예시 코드

현재 풀이 구조를 유지한 완전한 C++ 실행 코드입니다. 원래 제출 소스는 변경하지 않습니다.

```cpp
#include <iostream>
using namespace std;

int main() {
    int N;
    cin >> N;

    if ((N % 2 == 1 && N % 3 == 0) || (N % 2 == 0 && N % 5 == 0)) {
        cout << "true";
    } else {
        cout << "false";
    }
    return 0;
}
```

## 작은 값으로 따라가기

9는 첫 묶음, 10은 두 번째 묶음으로 true입니다. 6은 어느 묶음에도 속하지 않아 false입니다.

## 복잡도

시간·추가 공간 O(1).

## 확인 범위

문서의 예시 코드를 로컬 C++17 환경에서 컴파일하고, 문제 예제와 별도 확인 입력을 합해 2건의 출력을 대조했습니다. 비교 시 줄 끝 공백과 마지막 줄바꿈만 무시했습니다. 위 값 변화 설명은 코드 흐름을 수작업으로 추적한 내용입니다. 실행 시간 벤치마크나 코드트리 재제출은 하지 않았습니다.
