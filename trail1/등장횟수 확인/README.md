## 문제

$5$개의 수가 주어졌을 때, 짝수가 몇 번 등장했는지 확인해보는 프로그램을 작성해보세요.

## 입력

$5$개의 수가 한 줄에 하나씩 주어집니다.

## 제한 조건

- $1 \le \texttt{주어지는 정수} \le 1\,000$

## 출력

첫 번째 줄에 짝수가 등장한 횟수를 출력합니다.

## 입력 예제

### 예제 1

입력

```text
124
341
547
56
23
```

출력

```text
2
```
