## 문제

시험 결과가 $100$점일 경우에만 $0$등급을, 그 외엔 점수에 따른 등급 $1 \sim 9$를 부여하기로 했다. 오로지 등급 $0$만 `pass`고, 나머지 등급을 받은 사람들의 점수를 `failure`라고 출력하는 프로그램을 삼항연산자를 사용하여 작성해보세요.

## 입력

첫 번째 줄에 시험점수를 입력받습니다.

## 제한 조건

- $0 \le  \texttt{시험 점수}  \le 100$

## 출력

점수에 맞는 등급을 통해 `pass`인지 `failure`인지 출력한다.

## 입력 예제

### 예제 1

입력

```text
100
```

출력

```text
pass
```

### 예제 2

입력

```text
73
```

출력

```text
failure
```

## 제한

• Time Limit: 500 ms

• Memory Limit: 64 MiB
