## 문제

$2$개의 정수 $a$, $b$를 입력받아 $b$를 $a$에 더한 후, 다시 $a$를 $b$에 더한 뒤의 결과를 출력하는 프로그램을 작성해보세요.

예를 들어 $a = 1$, $b = 3$이었다면

$1$) $b$를 $a$에 더하게 되어 $a = 4$, $b = 3$ 이 되고  

$2$) 그 이후 $a$를 $b$에 더하게 되어 $a = 4$, $b = 7$이 됩니다.

## 입력

첫 번째 줄에 정수 $a$, $b$가 공백을 사이에 두고 주어집니다.

## 제한 조건

- $1 \le a, b \le 1,000$

## 출력

첫 번째 줄에 더하는 것을 진행한 이후 $a$, $b$ 에 들어있는 값을 각각 공백을 사이에 두고 출력합니다.

## 입력 예제

### 예제 1

입력

```text
1 3
```

출력

```text
4 7
```

• Time Limit: 500 ms
