## 현재 풀이와 좋은 점

성별로 나누고 각 분기에서 나이 19를 기준으로 성인 여부를 검사합니다.

## 다듬거나 기억할 부분

성별과 성인 여부라는 두 축을 나눈 현재 구조가 자연스럽습니다. 성인 기준이 여러 곳에서 쓰이면 const int adultAge=19로 이름을 줄 수 있습니다.

## 복습 예시 코드

현재 풀이 구조를 유지한 완전한 C++ 실행 코드입니다. 원래 제출 소스는 변경하지 않습니다.

```cpp
#include <iostream>
using namespace std;

int main() {
    int sex; int age;
    cin >> sex
        >> age;

    if (sex == 0) {
        if (19 <= age) {
            cout << "MAN";
        } else {
            cout << "BOY";
        }
    }
    else if (sex == 1) {
        if (19 <= age) {
            cout << "WOMAN";
        } else {
            cout << "GIRL";
        }
    }
    return 0;
}
```

## 작은 값으로 따라가기

성별 0·18세는 BOY, 0·19세는 MAN입니다. 경계 19를 포함하는 >=가 중요합니다.

## 복잡도

시간·추가 공간 O(1).

## 확인 범위

문서의 예시 코드를 로컬 C++17 환경에서 컴파일하고, 문제 예제와 별도 확인 입력을 합해 2건의 출력을 대조했습니다. 비교 시 줄 끝 공백과 마지막 줄바꿈만 무시했습니다. 위 값 변화 설명은 코드 흐름을 수작업으로 추적한 내용입니다. 실행 시간 벤치마크나 코드트리 재제출은 하지 않았습니다.
