## 현재 풀이와 좋은 점

첫 수 뒤의 문자 하나를 cin.get()으로 소비하고 두 수를 이어 출력합니다.

## 다듬거나 기억할 부분

소비하는 문자의 역할을 char separator로 명시하면 입력 형식을 더 쉽게 읽을 수 있습니다. 숫자 사이 공백 없이 출력하는 요구도 유지해야 합니다.

## 복습 예시 코드

현재 풀이 구조를 유지한 완전한 C++ 실행 코드입니다. 원래 제출 소스는 변경하지 않습니다.

```cpp
#include <iostream>
using namespace std;

int main() {
    int a; int b;

    cin >> a;
    cin.get();
    cin >> b;
    
    cout << a << b;
    return 0;
}
```

## 작은 값으로 따라가기

원문 예제 940312-1082836에서 두 정수가 읽히면 하이픈 없이 9403121082836이 됩니다. 양쪽 모두 맨 앞 숫자가 0이 아니라는 조건 덕분에 정수로 저장할 수 있습니다.

## 복잡도

시간·추가 공간 O(1).

## 확인 범위

문서의 예시 코드를 로컬 C++17 환경에서 컴파일하고, 문제 예제와 별도 확인 입력을 합해 1건의 출력을 대조했습니다. 비교 시 줄 끝 공백과 마지막 줄바꿈만 무시했습니다. 위 값 변화 설명은 코드 흐름을 수작업으로 추적한 내용입니다. 실행 시간 벤치마크나 코드트리 재제출은 하지 않았습니다.
