## 문제

$N$개의 정수가 주어졌을 때, 주어진 수 중 홀수이면서 $3$의 배수인 수들만 순서대로 출력하는 프로그램을 작성해보세요.

## 입력

첫 번째 줄에 정수 $N$이 주어집니다.

두 번째 줄부터 $N$개의 줄에 걸쳐 한 줄에 정수가 하나씩 주어집니다.

## 제한 조건

- $1 \le N \le 10$

- $1 \le $ 주어지는 정수 $ \le 100$

## 출력

주어진 수 중 홀수이면서 $3$의 배수인 수들을 주어진 순서대로 한 줄에 하나씩 출력합니다.

## 입력 예제

### 예제 1

입력

```text
5
2
7
3
9
4
```

출력

```text
3
9
```

• Time Limit: 500 ms
