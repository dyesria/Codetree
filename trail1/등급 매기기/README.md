## 문제

시험점수에 따라 등급을

$90$점 이상을 A,

$80$점 이상을 B,

$70$점 이상을 C,

$60$점 이상을 D,

$60$점 미만을 F 라고 합니다.

점수를 입력받아 등급을 출력하는 프로그램을 작성해주세요.

## 입력

첫 번째 줄에는 정수 $N$이 주어집니다.

## 제한 조건

- $0 \leq N \leq 100$

## 출력

점수에 해당하는 등급을 출력합니다.

## 입력 예제

### 예제 1

입력

```text
91
```

출력

```text
A
```

### 예제 2

입력

```text
76
```

출력

```text
C
```
