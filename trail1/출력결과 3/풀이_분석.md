## 핵심 원리

나머지를 이용해 두 수의 최대공약수를 찾는 유클리드 알고리즘입니다. tmp를 먼저 저장해 원래 a,b로 계산한 나머지를 보존합니다.

## 순서대로 따라가기

(128,2021) → (2021,128) → (128,101) → (101,27) → (27,20) → (20,7) → (7,6) → (6,1) → (1,0). 출력은 1입니다.

## 기억할 부분

b가 0이면 나머지 연산을 더 하지 않고 a를 출력합니다. 다음 단계 값으로 a와 b를 바꾸는 순서가 핵심입니다.

## 복습 예시 코드

제시 코드를 C++에서 확인하기 위한 완전한 실행 예시입니다. 필요한 main·출력을 보충하거나 위 설명에 맞게 정리했습니다.

```cpp
#include <iostream>
using namespace std;

int main() {
    int a = 128, b = 2021; 
    while (b != 0) {
        int tmp = a % b; 
        a = b;
        b = tmp;
    }
    cout << a << endl;
    return 0;
}
```

## 복잡도

고정 입력에서는 O(1); 양의 a,b로 일반화하면 시간 O(log(min(a,b)+1)), 추가 공간 O(1).

## 확인 범위

문서의 예시 코드를 로컬 C++17 환경에서 컴파일하고, 복습 확인 입력 1건의 출력을 대조했습니다. 비교 시 줄 끝 공백과 마지막 줄바꿈만 무시했습니다. 위 값 변화 설명은 코드 흐름을 수작업으로 추적한 내용입니다. 실행 시간 벤치마크나 코드트리 재제출은 하지 않았습니다.
